详细描述

Lightweight RPC envelope over a UdpLink (or any link exposing the same message callback). Wire format: u16 msgId + payload bytes, sent on channel 0.

C++ handlers receive NetReader&; script handlers receive the raw payload as a Squirrel string (build a NetReader with eve.Network().newReader(bytes)).
