template<class T>
class eve::Result< T >

Move-only operation result carrying either a value or Status.

Every Result is checked in an assertion-enabled build before destruction. Calling ok, status, value, error, a composition helper, ignore, or expect counts as an explicit observation. In release-style builds where ZEROERR_NO_ASSERT is defined, observation checks have no branch cost. The small observation token retains a stable ABI and the class remains [[nodiscard]] at compile time.

Result<U> implicitly converts to Result<T> when T is U with added const, including Result<T*> → Result<const T*>. Returning the const form makes value() yield a const view even from a non-const Result, so callers cannot mutate through a read-only operation.
