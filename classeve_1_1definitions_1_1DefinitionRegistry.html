详细描述

Deterministic registry of topic-neutral, versioned JSON definitions.

Returned Definition references remain valid until that key is replaced or removed, or until restoreJson() replaces registry state. The reference is a synchronous borrow; callers must not retain it across registry mutation.

◆ subscribe()

eve::Subscription eve::definitions::DefinitionRegistry::subscribe ( ChangeCallback  callback)

Subscribes to successful definition register, replace and remove operations.

参数
callbackSynchronously invoked after the registry state and event sequence have been updated. The callback receives a borrowed immutable event valid only for the callback call.
返回
Move-only token that cancels this registration on destruction.
警告
The registry and token are thread-affine. Subscribe, dispose, and registry mutations must run on the registry owner thread.
Callback dispatch is reentrant: a callback may add or remove subscriptions and may perform another registry operation. No registry lock is held while the callback runs.
备注
A successful restoreJson() is a bulk replacement and does not synthesize per-definition events; callers must re-query after restore because previously borrowed Definition references expire.
