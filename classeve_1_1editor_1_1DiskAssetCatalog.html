详细描述

Project Content scanner using stable .evmeta GUID sidecars.

A sidecar named Tree.png.evmeta describes Tree.png. Moving both files changes the logical URI while retaining identity. poll() is deliberately host-driven so desktop editors, games and MCP hosts can choose their own watcher/event loop without changing indexing semantics.
