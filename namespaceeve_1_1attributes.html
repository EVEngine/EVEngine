double eve::attributes::computeAttributeValue ( const AttributeValue &  attribute,
const AttributeOperationRegistry *  customOperations = nullptr 
)

Compute one attribute using the canonical operation order.

The order is base, all Add values, one summed AdditivePercent pass, all MultiplicativePercent factors, then priority/sequence ordered Override and Clamp operations. Custom policies participate in the final ordered phase.
