◆ restoreSnapshotJson()

eve::Result< void > eve::rpg::Tracker::restoreSnapshotJson ( std::string_view  json)

Validate and atomically restore quest progress against the current registry.

参数
jsonUTF-8 JSON produced by snapshotJson().
返回
Success after one commit, or a structured parse/schema/content failure.
备注
Unknown fields are ignored for version 1. Missing, removed, duplicated, or reordered quest/objective ids are rejected so content migration cannot silently lose progress. A failure leaves entries, ordering, and both event queues unchanged. @thread Call on the owning simulation thread. @reentrancy No callbacks are invoked.

eve::Result< std::string > eve::rpg::Tracker::snapshotJson ( ) const

Serialize persistent quest progress as deterministic versioned JSON.

返回
Owning JSON using schema eve.rpg.quest-tracker version 1, or a structured failure.
备注
Runtime event queues are transient and are intentionally excluded. The snapshot is bound to the currently registered quest and objective ids. @thread Call on the owning simulation thread; no internal synchronization is performed. @reentrancy No callbacks are invoked.
