Creates an ECS-owned UI host.

返回
A generation-checked handle; an empty handle means creation failed. @ownership The UI ECS world owns the host; callers must not delete it. @lifetime The handle is valid until ECS destruction or UI module teardown; resolve it at each use. @thread Call on the UI ECS thread. @reentrancy The factory invokes no external callbacks.
