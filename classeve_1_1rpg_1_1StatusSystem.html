◆ StackPolicyFn

using eve::rpg::StatusSystem::StackPolicyFn = std::function<int(RPGActor *actor, StatusInstance &existing, const EffectDefinition &def, const std::string &source)>

自定义叠加策略：在已有效果的临时 StatusInstance projection 上运行。

返回值约定与 apply() 相同（成功返回 adapter-owned 实例 id）。传入的 existing 永远是候选副本；策略不得通过 actor 直接修改状态或属性。 只有回调成功且候选数据通过校验后，StatusSystem 才会一次性提交 EffectContainer、AttributeSet 和 executor metadata。
