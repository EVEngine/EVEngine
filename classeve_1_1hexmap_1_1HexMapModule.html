详细描述

Owns the active hex map and the GPU meshes generated from it.

The module exposes exactly one editable map to scripts (the reference hex-map editor also edits a single grid). newGrid replaces it and releases the meshes generated from the previous map.

Ownership and lifetime:

  • The module owns HexMap and every graphics::Mesh it created.
  • chunkMeshAt returns a borrowed mesh; a Renderable3D may reference it only while this module is alive and the grid has not been replaced.
  • releaseMeshes must be called with the same Graphics device that created the meshes, before that device is destroyed.

Thread affinity: main/render thread only; no callbacks are invoked and no lock is held across an external call.

Replaces the active grid with an already-decoded map.

The load path: the payload was decoded into restored before this call, so the module only has to release the meshes of the previous grid, adopt the new one and rebuild its derived state (scratch, fog of war, mesh slots). The caller must follow it with a whole-map rebuild, because every chunk of the adopted grid starts dirty and no renderable points at the new meshes.

参数
gfxDevice that owns the current meshes; required.
restoredDecoded grid, moved into the module.
unitsUnit states to restore on the adopted grid.
返回
Success, or InvalidArgument when the device or unit states are invalid. @cost Releases every owned mesh and allocates the derived state for the new grid.

Regenerates the active grid procedurally and drops every unit.

The grid is rebuilt from seed first, because the terrain perturbation has to match the generation seed; that releases every mesh, unit and visibility counter of the previous grid. The caller must rebuild every chunk afterwards and place new units: a generated map has no explored cells, so nothing is visible until a unit grants vision.

参数
gfxDevice that owns the current meshes; required.
seedDeterministic seed for both the grid noise and the generator.
landPercentageTarget share of land, in percent; clamped by the generator.
waterLevelCells at or below this elevation are flooded; clamped by the generator.
riverPercentageTarget share of the map covered by rivers, in percent; clamped by the generator.
返回
Success, or InvalidArgument when there is no grid or no device, or a failure forwarded from the generator. @cost Releases every owned mesh and allocates the whole grid; proportional to the cell count.

Replaces the spherical map and releases the meshes of the previous one.

The sphere is a second, independent world alongside the flat grid: it shares the module's device and its cell record types, but neither the flat map nor its meshes are touched, so a script may hold both without one invalidating the other.

参数
gfxDevice used to release the previously created sphere meshes; required.
subdivisionTopology level in [0, kMaxHexSphereSubdivision].
radiusSphere radius in world units; must be finite and positive.
seedDeterministic seed for the sphere's noise field.
返回
Success, or InvalidArgument for a missing device or a bad shape. @cost Releases the previous sphere meshes and rebuilds the whole topology.
