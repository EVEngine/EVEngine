详细描述

Data-driven layered attack VFX recipe and element skin (Phase 1 schema).

Attack presentation is composed of ordered phases and typed layer slots that reference existing providers (MeshVFX, particles, decal, camera, …). Element identity is a reusable AttackVfxSkin (palette / profiles / overlay URI), not a hard-coded fire/water code path.

Phase 1 owns schema validation and serialization only; layer executors arrive in later phases. Runtime orchestration lives in AttackVfxRuntime.
