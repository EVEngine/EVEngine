详细描述

template<typename Tag>
class eve::rts::ServiceLink< Tag >

Strong key link to an external module-owned service object.

A service link retains only a stable logical key, never a provider pointer. The provider owns stale detection for its key; the RTS component remains valid when the optional provider is absent.
