◆ SubjectRef

using eve::sensing::SubjectRef = typedef ::eve::SubjectRef

Strong reference to a runtime subject.

This is a persistent identity, not an ECS entity handle. The nil value is rejected by all targeting operations. There is no implicit conversion to or from PersistentId, which prevents an AssetId/SubjectRef mix at call sites.

Compatibility spelling for the common subject reference.
