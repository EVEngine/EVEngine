详细描述

Versioned eve.action.guide-pack document codec and CPU landmark projection.

Owns the document protocol for the whitebox→AI-guide→2D-action pipeline. Does not own GPU capture, sprite ingest, or AbilityRuntime state. Wire keys use schema / schemaVersion (same convention as eve.action.ability).
