详细描述

Debug-only observation token shared by Result<T> specializations.

The token starts active for a newly-created Result. A move transfers its responsibility after payload movement succeeds; a moved-from Result is disarmed. The two bytes remain present in non-assert builds so Result keeps one ABI when a Release engine library is consumed by an assertion-enabled test or tool; the observation operations themselves compile to no-ops.
