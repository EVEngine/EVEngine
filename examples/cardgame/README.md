# Cardgame — 可玩的单机德州扑克

这是一个完整的双人无限注德州扑克示例：玩家与 AI 各有 1000 筹码，大小盲为 10/20，
庄位每手轮换。牌局按翻牌前、翻牌、转牌、河牌四轮下注推进，并执行标准烧牌流程；
摊牌时从两张底牌与五张公共牌中选出最佳五张牌，支持皇家同花顺到高牌的完整比较与平分底池。

示例使用 `eve.Card()` 管理 52 张牌、牌堆、手牌、公共牌布局和表现快照；规则、AI 与 UI
全部写在示例自己的 EveScript 中，没有为单个游戏改动引擎公共 API。AI 会依据起手牌、
当前成牌强度和底池赔率选择过牌、跟注、加注、全押或弃牌。

示例使用 MrEliptik 的
[Stylized Playing Cards Pack](https://mreliptik.itch.io/playing-cards-packs-52-cards)
黑底套装显示完整 52 张牌。原始 655×930 PNG 被等比例缩小为 262×372，降低示例的磁盘与显存开销；
素材采用 CC0，许可文本保存在 `assets/playing-cards/LICENSE.txt`。

## 运行

```bash
make run/<platform>-debug GAME=examples/cardgame
```

## 操作

| 输入 | 作用 |
|---|---|
| `C` 或界面按钮 | 过牌 / 跟注 |
| `R` 或界面按钮 | 加注（至少一个大盲，按有效筹码封顶） |
| `A` 或界面按钮 | 全押（按双方有效筹码封顶） |
| `F` 或界面按钮 | 弃牌 |
| `N` 或界面按钮 | 本手结束后开始下一手 |

左侧面板显示庄位、筹码、底池、本轮下注、当前牌型和完整牌局记录。任一方不足一个大盲时，
示例按现金桌方式自动补码到 1000，以便持续游玩。

牌型计算与 AI 强度函数位于 `poker_rules.nut`，启动时会自动执行皇家同花顺、A2345 顺子、
双三条葫芦和对子比较等规则自检。卡牌数据在 `data/cards.json`，脚本保存后支持热重载。
