# Stylized Playing Cards Pack

Source: <https://mreliptik.itch.io/playing-cards-packs-52-cards>

These 52 black-theme PNG cards were created and distributed by MrEliptik
(Victor Meunier). They are resized from 655x930 to 262x372 for this example;
the aspect ratio and alpha channel are preserved.

The pack is distributed under Creative Commons Zero (CC0). See the original
downloaded `LICENSE.txt` in this directory. The source pack also provides a
white PNG set and SVG source; those unused variants are not vendored here.
