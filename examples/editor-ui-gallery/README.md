# Editor UI Gallery

A runnable showcase for EVEngine's reusable editor UI kit. It composes the
semantic icon font, menu bar, toolbar, searchable sidebar, toolbox, draggable
split pane, cards, switches, badges, status bar and common form controls into a
single desktop workspace. A separate in-game HUD host is rendered beside it to
show that game UI and editor UI share the same retained controls, focus graph,
event router and accessibility metadata while keeping independent layout and a
nested dark theme scope.

```sh
eve run
```

Use **View → Toggle Theme** to compare the unified dark and light palettes.
The editor changes preset while the game HUD deliberately remains dark.
