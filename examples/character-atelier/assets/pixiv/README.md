## Rig adaptation

`female-rig.glb` is a modified binding adaptation of this same model, generated by
`../../prepare_rig.py`. Original vertex geometry, normals, UVs, morph targets and
textures are retained. Changes: 15 added facial joints and normalized four-weight
skin bindings; constraint helper skin influences rebound to corresponding FK
humanoid joints; VRM-specific extensions removed from the standard glTF derivative.
The example uses EVEngine's YSA material and skeletal pose presets. These changes
and rendered adaptations remain subject to the original VRM Public License 1.0
and settings. `rig.json` records the original SHA-256, controls and binding checks.
