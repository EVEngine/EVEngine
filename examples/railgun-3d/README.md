# 超电磁炮 3D

从 A 到 B 的 85 毫秒闪光，留下亮黄 → 橙红 → 暗红 → 冷却消失的弹道。
每隔 n 米生成垂直于射线的蓝灰烟圈，缓慢扩散上浮；320 颗白色到淡蓝色粒子向外飘散并淡出。
全部在真实世界空间中渲染，支持环绕观察；烟雾纹理由示例自带脚本生成。

```sh
make run/linux-debug GAME=examples/railgun-3d
```

Space 重新发射，A 切换自动发射（默认每 5.2 秒一次），O 切换相机环绕。
在 `main.nut` 的 `eve_init` 中调整 `a`、`b`、`spacing`（n，必须大于零）、
`flight`（飞行秒数）、`cooling`（冷却秒数）。修改这些参数后重新启动示例。
A/B 不得重合。粒子使用固定种子，可重复观看同一次发射。

资源在初始化时建立并复用，更新使用传入的秒制 dt；这是视觉特效，不进行物理碰撞。
烟圈使用带噪声和柔边透明度的朝向相机贴片，随时间扭曲、扩散并向世界 +Y 上浮。
燃灰向世界 +Y 升腾，叠加独立相位的横向摇曳，避免局部坐标导致下落。
光束使用高亮无光照加法材质与 Gaussian Pyramid Bloom。
`python3 examples/railgun-3d/assets/generate_smoke.py` 可在仓库根目录重建烟雾纹理。

V 切换弹道周围的局部体积光：柔边噪声介质 + 沿轨迹分布的发光代理，
使用 froxel 积分并按场景深度合成，随冷却由暖黄转红并衰减；不改变燃灰缓慢上浮速度。

性能实现：每圈恢复为 40 个柔边贴片，保留 320 颗燃灰及其原球体几何。
烟雾、燃灰和 48 段冷却弹道各合为一个静态网格；种子随顶点上传一次，
漂移、上浮、大小和颜色衰减在 GPU 顶点着色器计算，每帧只更新三个时间参数。
由 768 个独立透明物体降为三次绘制，不降低粒子数量或显示分辨率。
体积网格为 40×23×24，最多 6 个发光代理，每 0.12 秒更新一次，冷却结束后停止积分和合成。
窗口已恢复 1280×720 逻辑像素，2× HiDPI 桌面实际为 2560×1440。

着色器源文件和 SPIR-V 均随示例提供，Vulkan 运行时无需编译器。
修改源文件后执行 `bash examples/railgun-3d/assets/build_shaders.sh` 重建，
或通过 `GLSLANG_VALIDATOR` 指定编译器路径。本示例的合批着色器当前要求 Vulkan 后端。

本机实测：原尺寸、相同 40×10 烟雾与 320 燃灰，CPU 帧区间中位数从约 25 ms 降到约 1.5 ms。
当前设备日志为 llvmpipe 软件渲染，合批后的 GPU 计时仍约 57 ms 中位数；
这些数据只证明 CPU 提交开销改善，不能作为稳定 60 FPS 或独立显卡性能证据。
