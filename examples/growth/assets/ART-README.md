# Growth example art

Original pixel sprites and backdrop for `examples/growth`, generated for this
demo (not third-party game packs). DejaVu font license: `fonts/NOTICE.txt`.

| Path | Use |
| --- | --- |
| `bg/farm.png` | Sky / hills / pasture backdrop |
| `sprites/plot.png` | Tilled soil bed under the crop |
| `sprites/barn.png` | Barn prop |
| `sprites/fence.png` | Fence segment (tiled in script) |
| `sprites/wheat_*.png` | Crop stages: seed / sprout / ripe / stubble |
| `sprites/cow_*.png` | Livestock: calf / adult / pregnant |
| `sprites/item_*.png` | Yield chips: wheat sheaf / milk bottle |
| `sprites/sign.png` | Plot marker |
