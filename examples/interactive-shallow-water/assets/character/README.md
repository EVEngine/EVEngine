# Quaternius character subset

Reused from `examples/character-motion-lab/assets/quaternius`: Universal Base Characters Standard male full-body glTF and referenced textures/buffer, and Universal Animation Library Standard GLB. Both are CC0 1.0; original notices are included here. Geometry, skeletons, texture pixels and animation payloads are unchanged.

This scene imports Idle_Loop and Walk_Loop, retargets them using the existing explicit humanoid profile, and uses the animated toe positions for foot-contact events. It does not add foot-placement IK or change the source animation. See the source example README for distribution URLs, archive hashes and original glTF path corrections.
