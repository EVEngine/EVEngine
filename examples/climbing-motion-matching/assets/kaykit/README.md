# KayKit mannequin and motion libraries

This directory contains an unmodified CC0 subset of:

- [KayKit Character Animations 1.1 FREE](https://kaylousberg.itch.io/kaykit-character-animations)

The files are copied from the already verified repository fixture at
`examples/combat-action-editor/assets/kaykit/`. `Rig_Medium_MovementBasic.glb`
provides the generic mannequin, skeleton, locomotion and jump clips;
`Rig_Medium_MovementAdvanced.glb` provides strafing and dodge clips.
