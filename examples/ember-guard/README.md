# Ember Guard / 焰卫

俯视角法阵竞技场：青色长袍法师由六枚火球护卫。紫色敌人持续从外围入场，火球在 260 像素范围内自动选择未被锁定的最近敌人，命中后返回轨道，冷却后再次出击。每个敌人承受两次命中。

展示半透明辉光、渐细火焰拖尾、命中火星、轨道运动与自主索敌。辉光使用透明纹理叠绘，没有使用真实动态光照或 Bloom 后处理。人物是程序化图形绘制，无外部模型依赖。

```sh
make run/win32-debug GAME=examples/ember-guard
```

WASD / 方向键移动；停止操作五秒后恢复自动巡游。无需操作即可持续演示。

`main.nut` 包含场景和固定 120 Hz 模拟，`config.nut` 配置窗口，`assets/` 包含圆形与辉光纹理及附带许可的字体。模拟时间由引擎 dt 注入，入场方位使用确定性序列，不调用随机数；帧时间最多补算 0.1 秒，因此不声称跨帧率重放一致性。所有目标和特效均为场景内部状态，不修改引擎公共 API 或持久格式。
