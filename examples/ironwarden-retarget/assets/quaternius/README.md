# Human source skeleton and motion

`AnimationLibrary.glb` is an unchanged copy of the CC0 Quaternius animation
library already shipped with `examples/character-motion-lab`. The author provides
46 clips, including the eight selected here. Both the human skeleton and visible
mannequin come from this asset; no source animation is copied into the target GLB.

Source: https://opengameart.org/content/universal-animation-library
