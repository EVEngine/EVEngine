# Softbody — Cloth & Fluid

Interactive demo for the Physics module's cloth and 2D fluid solvers.

## Run

```bash
make run/linux-debug GAME=examples/softbody
```

## Controls

| Input | Action |
|-------|--------|
| Left drag (left panel) | Grab / drag cloth |
| Left drag (tank) | Repel fluid |
| Right drag (tank) | Attract fluid |
| Space | Emit fluid at cursor |
| R | Reset scene |
