## Rig adaptation

`female-rig.glb` is the same binding adaptation used by `examples/character-atelier`,
generated by that example's `prepare_rig.py`. Original vertex geometry, normals, UVs,
morph targets and textures are retained. Changes: 15 added facial joints and
normalized four-weight skin bindings; constraint helper skin influences rebound to
corresponding FK humanoid joints; VRM-specific extensions removed from the standard
glTF derivative. These changes remain subject to the original VRM Public License 1.0.
