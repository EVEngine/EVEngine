# PixelWorld

一个可直接运行的 Noita 风格二维材料仿真切片：沙与水按密度流动，火焰点燃木材/油并把水转成蒸汽。世界逻辑使用固定 tick，渲染只是对权威材料网格的投影。

```sh
cd examples/pixelworld
../../build/linux-debug/src/engine/eve run
```

操作：

- 鼠标左键：绘制当前材料；右键：挖除地形；中键：点火。
- `1`–`9`：选择沙、水、油、木材、石头、火焰、酸液、火药、熔岩。
- `-` / `+`：调整笔刷半径。
- `F`：在油池附近点火；`O`：投放油；`R`：重置场景。
- `E`：在鼠标位置触发带径向热量的确定性爆炸。
- `D`：切换 Chunk 活跃/休眠/温度边框和右上角最近 60 Tick 耗时图。

地形和动态材料共享同一权威像素网格。挖掘会直接将目标材料替换为
`air`，不存在与材料状态可能失同步的第二套破坏遮罩。
