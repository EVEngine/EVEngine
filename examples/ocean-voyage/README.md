# Ocean Voyage

可驾驶的 055 展示舰与广阔海洋：三频段 JONSWAP/FFT、40 公里海面分级网格、
GPU 驻留位移、真实 World3D 浮力与推进、局部尾浪、泡沫及三维飞沫。
使用仓库内 [055 模型](../../assets/models/type055/README.md)，保留 180 米原始尺寸与四组材质。
无需额外下载；从示例工作目录只读挂载 `../../assets/models/type055`，发布时也需带上该目录。

```sh
make run/linux-debug GAME=examples/ocean-voyage
```

当前示例明确要求 Vulkan GPU 计算和绘制路径；初始化失败会报告 Result 诊断，
不静默改为 CPU。软件 Vulkan 也可运行，但实时性能仍需测量。

- W / S：前进 / 倒车。
- A / D：船舵。
- C：自动巡航开关，默认开启；开场已有 12 米/秒前向速度，随后由推进力和水阻驱动。
- P：暂停仿真。
- V：飞沫显示开关，仅影响绘制；可暂停后比较相同海面与船位。
- T：俯视 / 跟随镜头，便于检查舰首隆起、两侧后向波列和舰尾尾迹。

统一 60 Hz 整数 tick 驱动谱帧、船体、尾浪。每帧最多补四步，剩余积累时间保留。
显示位置来自刚体姿态；海面中心跟随船只，尾浪窗口按整数格滚动并保留重叠历史。
同一 VM 的脚本热重载保留运行中的原生对象根；它不标记为 persist，也不冒充可序列化检查点。
仅驾驶输入和观测投影使用 persist；销毁/恢复 World3D 后需按新 body 重建 OceanBoat。

接口说明见 [海洋脚本 API](../../docs/usr/ocean.md)。
海岸和水下效果尚在系统后续阶段，不能把本示例作为这些能力的验收。

`game.agent.json` 提供正式 Play Host 契约：`ocean-ready` 观察 tick、船速与完整姿态；
forward/stop/left/right/straight/pause/resume 修改驾驶或暂停输入，不直接移动刚体；
spray-on/spray-off 修改飞沫显示开关。观测同时给出飞沫 alive/emitted/dropped。
`voyageTelemetry` 是只读观测投影，不是恢复或仿真权威。通过 `eve_play` 驾驶和观察，
通过引擎 readback 捕获画面，不使用 eve_eval 操纵游戏。
观测还包含前向航速、相机位置和船外三点的尾浪最大绝对高度/泡沫覆盖率，
可核验船、镜头和尾迹是否实际推进，而非仅看一张静态图。

三维飞沫由同一船体接触 receipt 和水面查询驱动，固定步只推进一次；
拥有型不可变帧投影为按相机深度排序的透明四边形，海面与刚体不读取渲染状态。

模型 +X 舰首通过局部旋转对齐刚体 +Z 前进方向；旋转与刚体四元数完整组合，
升沉、横摇、纵摇均来自同一个 World3D。模型原点为设计水线，不另加视觉起伏。
16 个浮力采样点、约 8208 吨箱体质量/惯性代理、推进与舵力用于交互展示，
并非真实 055 排水量、碰撞外形或操纵性能参数。默认有效波高 0.65 米、峰值周期 9 秒，
尾浪窗口 384 米，泡沫衰减率 0.22/秒、波动阻尼 0.08/秒，保留驶过水域的尾迹；
海面网格为 256 段、192 圈，以分辨近船波纹。舰首斜侧镜头用固定仿真时间平滑跟随
位置和航向，视线朝向舰尾以同时看到舰首浪和尾迹；暂停时镜头也停止。

谱海面驱动浮力和水阻，船体接触反过来生成局部尾浪及飞沫。此示例不将本舰生成的
近似尾浪再反馈给本舰浮力，以免大排水体积的重复激励使船体自行抬升；
这不是双向压力耦合或舰船 CFD。尾浪仍实际推进、衰减、随窗口滚动，并参与水面绘制。
每艘船的接触采样共享一个按排水体积加权的激励预算，避免多采样点重复激励导致
波速和泡沫场持续饱和。舰首抬升与后向波列由移动激励和色散传播产生，不是水面贴花。
水平航行激励按迎水端距离集中分配，垂向拍水仍按各浮力接触点注入；倒船时迎水端随之反转。
局部尾浪中抬升且陡峭的波面会持续生成白沫，随后沿用泡沫场的输运和衰减；
这是线性色散求解器上的视觉破碎近似，不模拟浪头翻卷。着色器将覆盖率分成斑驳泡沫，
不再把接触区域画成均匀光晕。多接触点船体的飞沫集中在迎水端四分之一，
用接触单元体积估计外侧水线发射位置并向外抛出，避免飞沫被船壳遮住；
这一位置是浮力单元代理，不是精确船壳相交计算。

舰体使用低反光冷灰、较浅上层建筑、深色窗/设备和灰白标线；直接设置导入的 Material，
因为它会覆盖 Renderable3D 的 tint/roughness。海水使用随波面朝向变化的体散射，
太阳高光按像素法线变化过滤，减少俯视时孤立的白色三角亮斑。
Play Host 的 `top-view` / `chase-view` 可切换视角；暂停时也能切换以检查同一波形。

`type055.nut` 的八段保守遮水体依据 SCAD 船壳站位，侧面向内收 2 厘米，
每个渲染 tick 使用刚体位置与四元数投影。只裁除内部海面，浮力仍查询完整水面；
上边界不超过对应段最低甲板，高于甲板的浪仍可显示。若修改船壳站位，需同步调整代理。
替换模型或代理后需重启示例；同 VM 热重载刻意保留既有原生对象。
