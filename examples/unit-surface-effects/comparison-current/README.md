# 当前同模型对照

- `overheat-arms-before-after.png`：最新过热修订，双臂热区与轻微表面燃烧。

- `alignment-before-after.png`：本轮充能、过热、金属化、木质化的概念、改前、改后，同一时刻与裁切。
- `alignment-five-effects.png`：上一轮冰霜、治疗、暗影、潮湿、减速的对照归档。
- `reference-vs-render.png`：左侧 AI 概念目标，右侧引擎实渲。
- `rendered-26.png`：26 项各自独立呈现的代表帧，加中性材质。
- `timeline-26.png`：每项四个时间节点的缩略总览。
- `sequences/`：每项全部 12 帧的时间序列，短脉冲使用更细时间步长。
- `captures/`：未经修色的原始 1280×800 PNG。
- `manifest.json`：模拟时间、选帧、统一裁切框与原始文件 SHA-256。
- `VISUAL_REVIEW.md`：按实际画面记录形态与剩余差距。

所有效果使用同一装甲网格、中性基线、相机、光照、曝光和尺寸；先逐个连续播放，
再暂停并注入确定的模拟时间。只通过引擎 `eve_screenshot` 获取原始帧。
拼图只统一裁切、缩放、加标签；没有用生成图替换或修改实际渲染。

与旧 `../comparison` 相比，本轮统一了单位空间，增加材质/法线/粗糙度响应、
实际隐身及切除、独立受击环和传送碎块，并显式配置透明队列以避免发光层被覆盖。
这是一轮可复核的实现成果；图册完整和动画变化不等于所有概念细节已通过视觉验收。
