# 同模型逐项视觉复核

依据本目录原始帧、26 项拼板和每项 12 帧序列。对照目标为
`assets/styles/unit-surface/reference/same-mesh-26.png`，由同一中性模型生成。
不同效果的代表时刻按各自时间包络选择，图中标注时间；不是只挑总览中的小区域。

本轮已解决：测试模型不一致、子网格分别重启图案、所有效果仅染色、材质盖住发光层、
传送/相位主体不消失、受击全身泛白、电击平行波纹、充能/吸血多个中心。
实际图像仍不能称为概念图的完整视觉验收。以下区分已有形态与具体差距。

| 效果 | 实际呈现及本轮判断 | 与概念目标的剩余差距 |
|---|---|---|
| 01 护盾 | 统一密度的蓝色多面网格、亮边与纵向脉冲 | 转折处网格投影仍能看出三向混合 |
| 02 受击 | 胸部局部亮核、橙色裂纹、独立扩散环、迅速衰减 | 没有离面飞散的火花 |
| 03 冰霜 | 细晶切面、局部霜面受光、少量轮廓尖晶；弱化了粗网格与重复符号 | 晶体簇仍偏细密程序纹理，离面碎霜与参考的自然分叉层级还不足 |
| 04 灼烧 | 焦黑粗糙斑与发热裂缝，上行热脉冲 | 未加离面火舌和灰烬，裂纹仍较均匀 |
| 05 毒蚀 | 腐蚀斑、明亮黄绿边界、轻微流动 | 液膜高光和蚀坑深浅仍有限 |
| 06 治疗 | 主上升波、少量十字、三条独立绕体环管，后半圈接受身体遮挡 | 光环目前等距循环；参考的非均匀流动和更多离面十字尚未实现 |
| 07 电击 | 蓝白不规则折线、短支路与闪断 | 没有伸出轮廓的空间电弧 |
| 08 石化 | 石面粗糙受光、裂沟、覆盖生长后保持 | 岩片细节与自然石纹仍偏规则；默认保留部分装甲 |
| 09 隐身 | 主体透明，仅保留青色边与稀疏提示点 | 不含场景折射；背面透叠是当前透明方案的表现 |
| 10 相位 | 主体实际切除，紫色断续边界 | 没有独立薄片的空间错位 |
| 11 净化 | 单条金白下降洗涤波与稀疏亮点 | 没有离面金色竖直光束 |
| 12 诅咒 | 分散的多种角形符文与紫色脉冲 | 符号较少，未覆盖参考中的复杂图腾层级 |
| 13 狂暴 | 红色弯曲脉络与双拍亮度变化 | 脉络密度和分支仍少于目标 |
| 14 神圣护甲 | 按装甲板片边缘分区的金色边框 | 外晕较克制，未模拟边缘放射光束 |
| 15 暗影侵蚀 | 暗紫材质与十条独立螺旋曲带，烟丝扩展至轮廓外 | 曲带近似仍比参考烟雾薄，没有体积散射与柔软烟团 |
| 16 能量充能 | 单一胸部节点、胸腹多级电路分支、板边提示与流动包 | 路径仍较对称，缺少参考的肩部离面电节点 |
| 17 过热 | 双臂热边与断续散热线、肩部到前臂的局部亮区；胸腹叠加向上流动的薄火光，保留暗色板片 | 目前是表面火光，没有离面火焰、热扰动或烟气；散热线仍是单位坐标投影 |
| 18 潮湿 | 暗湿材质、表面水珠高光及稀疏下落水滴，去除重复碎线覆盖 | 细微液膜仍不够丰富，不含真实场景反射和折射 |
| 19 流沙 | 粒状黄褐覆盖、局部流动与粗糙受光 | 无离面沙尘聚散；当前更接近沙覆层 |
| 20 金属化 | 中性银灰反射、窄亮带与深色区，减轻蓝黑偏色 | 使用解析棚灯近似，不反射实际场景；复杂环境层次仍不足 |
| 21 木质化 | 较浅的木色、细长纤维和纵向凹沟、局部绿缝 | 仍是表面程序材质，纤维方向偏整齐，无翘皮或苔藓体积 |
| 22 裂解 | 深色裂片与洋红裂缝；手动进度可切除片区 | 默认展示裂纹，未实现独立多边形碎片飞离 |
| 23 扫描 | 明确青色主扫线与较暗技术网格 | 无离面扫描光束，网格仍贴表面 |
| 24 传送 | 主体切除与上升边界同步，蓝紫稀疏立方碎块 | 碎块为预制网格种子，非原装甲真实切块 |
| 25 时间减速 | 连续表面等高线加三条缓慢倾斜绕体环管，线宽在斜视角仍连续 | 环数和局部流线分层少于参考，无屏幕空间时间畸变 |
| 26 吸血 | 单一胸部红色中心与向内弯曲流线 | 只有表面流线，没有跨单位的吸取粒子 |

本轮拒绝了重复蕨形冰纹、膨胀人形暗影壳，以及斜视角断续的薄片光环。

木/石材质细节以及湿膜的受光细节；这些仍不能视为完整概念图验收通过。

早期试验帧仅保留在作者本地工作区；本目录包含最终实现证据。
