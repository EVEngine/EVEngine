◆ child()

template<typename Tag >
Id128 eve::detail::Id128< Tag >::child ( std::string_view  role) const
inlinenoexcept

Derives a deterministic child UUID for a hierarchical identity.

参数
roleNon-empty, caller-canonicalized role or child key.
返回
A stable child identity, or nil for a nil parent or empty role.
备注
This is a namespace derivation operation. It is not a source of new instance entropy; use UUIDv7 generation for top-level identities. The operation is kept in the common UUID type so compatibility aliases cannot grow a second identity algorithm.
