详细描述

Optional owning capability registration (shared_ptr + generation + lease).

Elevates the model validated by editing::ExtensionProviderRegistry into the common capability layer (R-COHESION-3). Bare provide/query remain the default borrowed path; this header is for families that need ownership, stale-handle detection, or thread-safe register/unload.
