◆ publishGameplay()

eve::Result< void > eve::inventory::Inventory::publishGameplay ( const std::string &  instanceId,
const std::string &  ownerId,
Bag *  bag,
EquipmentSet *  equipment = nullptr 
)

把一个玩家背包实例发布到共享玩法协议（eve_gameplay / MCP）。

领域动作词表就是本模块自己的操作（add/remove/split/equip/unequip）， 因此 Agent 与玩家走同一条权威写入路径，而不是另开一条调试旁路。 一个模块只注册一个领域适配器（共享路由器要求每个领域唯一），该适配器 服务全部已发布实例；同一 instanceId 重复发布返回 Conflict。

参数
instanceId实例稳定标识，必须是规范持久 id（UUID 文本，如 00000000-0000-7000-8000-000000000701），与 eve_gameplay 的 request.instance 逐字一致。
ownerId控制该实例的玩家/角色稳定标识，同为规范持久 id （session.controlledSubjects 校验用）。
bag借用容器，必须比本次发布存活更久。
equipment借用装备栏，可为 null（则实例没有装备动作）。
返回
成功时返回空结果；实例 id 非法、重复或 bag 为空时返回诊断。 @ownership 适配器由本模块持有并随模块销毁；bag / equipment 所有权不变。 @thread 所有者模拟线程。
