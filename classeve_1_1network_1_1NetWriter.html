详细描述

Typed little-endian reader/writer for network payloads.

Length-prefixed values (writeString / bytes) use a uint32 little-endian length followed by the raw bytes. All fixed-size types are little-endian. NetReader failures are sticky: after any out-of-bounds or malformed read, ok() returns false and subsequent reads safely return defaults.
