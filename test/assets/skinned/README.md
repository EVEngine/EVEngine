# Skinned character fixtures

Run `scripts/download_skinned_character.sh` (or `make download-skinned-character`) to refresh **CesiumMan** under `cesium_man/glTF/`.

The glTF files are also **committed in-repo** (~464 KiB) so CI and offline builds do not depend on a network fetch.
