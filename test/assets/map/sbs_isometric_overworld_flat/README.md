# SBS Isometric Overworld test assets

These three source atlases are the minimum fixture set used by
`map.dualGridMask.worldSpaceFourMaterialPreview` to exercise grass, sand,
stone, and water blending with real isometric artwork.

- Author: Screaming Brain Studios
- Source: https://screamingbrainstudios.itch.io/iso-overworld-pack
- Upstream pack: `SBS - Isometric Overworld Pack - Large`
- Variant: `Overworld - Large/Flat` (256x128 tiles)
- License: CC0 1.0 Universal; see `LICENSE-CC0-1.0.txt`

The files are renamed only to give the tests stable, shell-friendly paths.
Their image content is unchanged.
