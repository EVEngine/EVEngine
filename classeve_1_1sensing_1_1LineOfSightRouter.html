详细描述

Routes each line-of-sight query to the backend that claimed its coordinate space.

@thread Affine to the caller; it holds borrowed pointers and does no synchronization. Claim all backends during startup, before queries run. @reentrancy query invokes the selected backend synchronously and performs no locking.

Claim one coordinate space for a backend.

参数
spaceSpace this backend can interpret; it must be one of the four enum values.
providerBackend to answer with.
返回
Applied, InvalidArgument for a null provider, or Conflict when the space is taken. @ownership Borrowed: the router never owns or deletes the backend. The claiming module must keep it alive for as long as it is claimed. @lifetime Valid until removeProvider releases that exact space and provider.
