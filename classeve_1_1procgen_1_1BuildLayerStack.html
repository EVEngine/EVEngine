详细描述

Ordered, versioned executor for procedural tile and object build layers.

The stack owns all definitions. Execution creates a new result and publishes no partial artifacts if a layer fails. No scene, renderer or physics state is owned. @thread Affine; mutate and execute on the owning thread.
