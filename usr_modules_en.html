Module Handbook

Module Handbook

中文 · User guide · API conventions

Download an SDK from Releases, unzip it and run eve run <game-directory>. No engine compilation is needed.

Guides explain tasks, working examples, ownership and failure handling. Exact C++ signatures belong in Doxygen; callable EveScript signatures belong in the SDK's share/eve/ai/eve-api.json or editor/MCP API lookup. A C++ public method is not necessarily script-callable.

English guides are maintained by hand with Chinese as the authoritative source. This first batch covers onboarding, language, saving and common game-development workflows. Links marked Chinese lead to guides not yet translated; they remain useful and are not represented as English documentation.

Use has_module("slot") for optional features. Project module selection and source-build trimming are different; see EveScript and module trimming.

SCAD and LDraw model import converts procedural solids and part assemblies into canonical native static prefabs.
