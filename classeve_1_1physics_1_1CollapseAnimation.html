详细描述

Owning, solver-independent baked rigid-fragment animation within Physics. @ownership Owns all samples; retains no instance/world pointers. @thread Mutation requires exclusive access. Const sampling/saving may run concurrently when no caller mutates the clip. Sampling/saving have no callbacks. Copies may play independently. capture synchronously invokes the source interface without locks; source methods must not reenter or mutate this clip, and the source must remain stable throughout the call. @lifetime Valid after source instance/world destruction and process restart. File schema EVECOLL1 versions 3/4 checksum all bytes (noncryptographic); v4 embeds provenance. Versions 1/2 load as unverified legacy input; saving upgrades them. Version 1 migrates as boxes. Unknown versions, trailing bytes and malformed data are rejected before publication.

◆ save()

Result< void > eve::physics::CollapseAnimation::save ( std::string_view  path) const

Save a new file; refuses existing paths to preserve previous bakes. @cost Linear in recorded samples, with one bounded serialized buffer; perform outside the frame loop.

返回
Checked IO status. Complete staged data is published without replacement. Filesystems without hard links fail explicitly. Linux syncs data before publication and the parent directory afterwards; other platforms currently guarantee atomic visibility only. Storage must honor fsync. Linux requires anonymous O_TMPFILE staging and procfs descriptor links; unsupported staging fails explicitly. A Linux barrier failure carries publication=not_published or published and durability=unconfirmed diagnostic details. A published failure leaves a complete target: inspect it before deciding to retry. Failure never removes the target; only this call's private temporary files are cleaned.
