◆ parseUuidText()

std::optional< UuidBytes > eve::detail::parseUuidText ( std::string_view  text)
noexcept

Parses canonical UUID text without knowing the domain tag.

The tagged Id128<Tag> methods below only forward here. Keeping parse, format and derivation non-template means one machine-code copy each instead of one per domain tag, while the tag set stays open: adding a domain tag no longer duplicates any of them.

参数
textA 36-character UUID with 8-4-4-4-12 hexadecimal groups.
返回
The bytes, or empty when the text is malformed.
