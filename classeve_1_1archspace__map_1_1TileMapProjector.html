详细描述

Projects an ArchSpace level onto a map::TileLayer (orthogonal or isometric).

Builds GridProjection via bakeGridProjection, then writes GIDs and navigation metadata. Orientation is applied through TileLayer::applyConfig.

@ownership Optionally owns a TileLayer created on first sync (released via Entity::release); borrowed layers set via setLayer are never released. @thread Owner thread only.
