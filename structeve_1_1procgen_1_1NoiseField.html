详细描述

Deterministic 2D noise helpers for pixel textures and masks.

Covers the common NoiseCreator / noisecreater.com / Musgrave set: white, value, Perlin, Simplex, Worley (F1/F2/edge/smooth + metrics), fBm / ridged / billow / swiss / hybrid / jordan, Gabor, Perlin–Worley, hex, gyroid, curl, value derivatives / isoline / banding, color-channel fBm, and single- or multi-pass domain warp.

When periodX/periodY > 0, lattice indices wrap for seamless tiling. Continuous samplers return values in [0, 1] unless noted.
