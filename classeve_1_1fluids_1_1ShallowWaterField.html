详细描述

GPU-first shallow-water (2D Saint-Venant) free-surface solver.

Owns height h, momentum (hu, hv) and bed b on a Cartesian XZ grid. The CPU reference mirrors the GLSL kernels 1:1 and is selected automatically when compute is unavailable. Character-leg capsules write displacement / momentum sources before each integrate pass.

@thread Graphics/device owner thread for GPU path; CPU path is reentrant for distinct instances only.

Pack per-cell depth / velocity into an RGBA8 image (resolutionX × resolutionZ).

参数
imageDestination; must be RGBA8 with width=resolutionX and height=resolutionZ.
velocityScaleHorizontal speed that maps to the full channel range, in (0, 50].
depthContrastWhen <= 0, R stores absolute h / maxDepth. When > 0, R stores a crest heat map clamp((h - meanH) / depthContrast, 0, 1) so rest water stays dark and centimetre waves still paint red (range (0, maxDepth]).

Channel layout (row z, column x, matching mesh UVs):

  • R: water depth (absolute h/maxDepth, or crest heat when depthContrast > 0)
  • G: 0.5 + 0.5 * clamp(vx / velocityScale, -1, 1)
  • B: 0.5 + 0.5 * clamp(vz / velocityScale, -1, 1)
  • A: clamp(|v| / velocityScale, 0, 1) (foam / speed mask) @ownership Does not retain image; caller owns the pixel buffer for the call duration.
    返回
    Success, or InvalidArgument when the image shape/format/scale is rejected.
