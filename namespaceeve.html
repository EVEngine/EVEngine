 Resource is a game object that is managed by the ResourceManager. It can be loaded from a file or generated at runtime. If the resource is loaded from file, a monitor will be created to watch the file changes. When the file is modified, the resource will be reloaded. If the resource is generated at runtime, it can depend on a few other resources and the ResourceManager will update the resource when the dependencies are changed. 更多...

◆ exposeReflection()

void eve::exposeReflection ( Runtime &  runtime,
ssq::Table  eveTable 
)

Exposes the Runtime reflection API to scripts as eve.reflect.

Adds a reflect sub-table to the eve table with class/instance introspection, typed property read/write and array/table member editing:

local info = eve.reflect.classInfo("Hero") // class metadata table
local hero = eve.reflect.createInstance("Hero")
eve.reflect.write(hero, "hp", 42.5)
local hp = eve.reflect.read(hero, "hp") // 42.5
local members = eve.reflect.inspect(hero) // member metadata + live values
eve
Build metadata (engine git commit, build time, third-party version).
Definition Build.cpp:16

Scalar reads/writes keep the slot's own type (bool stays bool, integer stays integer, ...), mirroring Runtime::writeProperty; array, table and instance slots are read as their live script objects. classInfo() returns null for an unknown class, and every mutator returns false instead of throwing when the member is missing, is a method, or is not editable.

参数
runtimeRuntime whose reflection data the bindings operate on.
eveTableRoot eve table to add the reflect sub-table to.

◆ reflectedFloatString()

std::string eve::reflectedFloatString ( double  value)
inline

Shortest round-trip float formatting (portable).

std::to_chars(float/double) is unavailable on Apple platforms with an iOS deployment target below 16.3, so reflection/editor code must not use it. snprintf with max_digits10 guarantees round-tripping at the cost of not being the shortest spelling.
