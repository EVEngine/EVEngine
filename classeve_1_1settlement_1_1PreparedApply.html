详细描述

Prepared domain mutation used to make settlement application atomic.

A policy creates this object from a candidate copy or equivalent private transaction. commit must make the candidate observable atomically; the supplied rollback callback must restore the previous state if a later event append fails. The object is synchronous and must not retain temporary request/context references.
