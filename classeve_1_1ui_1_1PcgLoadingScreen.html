详细描述

Caller-owned loading-screen state driven by Pcg terrain load-progress events.

The terrain loader forwards start, update, end and timeout events. This object owns diagnostic strings, invokes no callbacks and exposes an immutable UI snapshot through getters. @thread UI thread only.
