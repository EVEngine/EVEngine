◆ ReloadPolicy

enum class eve::definition::ReloadPolicy : std::uint8_t
strong

Policy used when a live definition is replaced.

枚举值
KeepInstanceValues 

Replace the definition generation and preserve all instance values.

ReapplyDefaults 

Replace the typed state with defaults produced from the new definition.

RebuildInstance 

Let the consumer atomically construct a new state from the new definition.

RejectWhileActive 

Reject the reload while the instance is active; inactive instances keep values.
