详细描述

Adapts one Bag's item quantities to the common resource protocol.

Each ResourceId is the canonical ItemDefinition id. The bag's slot vector remains the only balance store; this adapter owns only reservation records and an opaque AccountNonce. It therefore works for both item prices and weapon ammunition without creating a second resource map. The Bag is borrowed and must outlive this adapter. Calls are synchronous on the Bag owner thread. Failed multi-item mutations restore slots, generated instance ids and queued inventory events before returning.
