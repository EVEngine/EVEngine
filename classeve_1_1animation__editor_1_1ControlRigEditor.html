详细描述

UI-independent rig authoring controller with existing editing transactions. @ownership Owns document, skeleton snapshot and previews. Call arguments borrowed synchronously. @thread Owner thread only. @reentrancy Does not invoke scripts or unknown callbacks.

Result< void > eve::animation_editor::ControlRigEditor::enableAutomation ( )

Register the initialized live document and existing history with the active editor host.

返回
Structured unsupported status when the host is absent; duplicate target IDs are rejected. @ownership Borrows the host with a teardown sentinel; destruction unregisters this target. @thread Owner thread only. No scripts are invoked.
