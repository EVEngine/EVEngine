Cook an owning canonical mesh into a geometry-collection asset.

Compatibility-only proxy cook: Voronoi mode names here describe site placement, not a tessellation. Use cookVoronoi from VoronoiCook.h for actual closed convex fragments, shared-face adjacency, interior caps and exact convex collision. The legacy proxy shape and seed behavior remain unchanged.

参数
meshBorrowed immutable mesh retained only for this synchronous call.
recipeValidated fracture recipe; randomness uses only seed+stream name.
返回
Complete validated asset, or a checked diagnostic with no partial publish. @thread Worker-safe and reentrant; no IO, callbacks, or global mutation.
