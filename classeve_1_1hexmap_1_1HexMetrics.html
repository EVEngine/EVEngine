详细描述

Hexagon metrics shared by the map model and every mesh builder.

The layout matches the Catlike Coding "Hex Map" reference project: pointy-top hexes on the XZ plane, +X east, +Z north, odd rows shifted half a cell to the right, Y up. All radii are expressed in world units; outerRadius is settable so a caller can rescale the whole map without touching the derived ratios.
