详细描述

Embedded Model Context Protocol (MCP) server for AI-assisted game development.

Speaks JSON-RPC 2.0 over TCP with newline-delimited messages (same wire shape as MCP stdio; no embedded newlines in payloads). Start with listen(port) after DevTool::attach; call poll() from the game loop / pause pump.

Capabilities: tools, resources, prompts for AI test workflows. Cursor / Claude Desktop can attach via tools/eve-mcp (stdio ↔ TCP bridge).

Desktop-only (part of EVDevTools); not shipped on Android/iOS trimmed runtimes.

Switch to stdio transport (MCP stdio server). A reader thread pulls newline-delimited JSON from in into a queue that poll() drains on the caller thread, so tool execution stays on the main / render thread. Responses are written to out (stdout by default — keep it MCP-only). Returns true when the transport starts.
