 Validates and binds a graph snapshot to an existing Physics body.
 

详细描述

Runtime instance binding one immutable graph generation to one Physics body.

The instance owns topology and reservations, but stores only generation-checked Physics handles. It never retains World3D or Body3D pointers across calls.

Claims a snapshot reservation by transfer or exact-slot reacquisition.

A still-live matching credential is transferred and invalidated. If its prior owner already released it, the authored slot is reacquired only when still free. A conflicting live claim is never displaced.
