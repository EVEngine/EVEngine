详细描述

Derived cluster cache that incrementally executes a BuildLayerStack.

Grid hashes include a one-cell halo so tile-side geometry is invalidated when a neighboring cluster changes. Point ownership follows the source point's half-open world-space cluster. Updates are transactional and preserve the old cache on failure. @thread Affine; update and query on the owning thread.
