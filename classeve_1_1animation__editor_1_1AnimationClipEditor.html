详细描述

Timeline-style controller for one authored animation clip.

Owns the clip document, local undo, deterministic scrub preview and a renderer-neutral skeleton overlay. Script presenters draw layout getters only.

@ownership Editor owns the document. Overlay snapshots are copied values. @threadaffinity Owner thread only. @reentrancy No unknown callbacks.
