详细描述

template<class T, class Tag>
class eve::script::RuntimeObjectRegistry< T, Tag >

Slot/generation registry whose objects are exclusively unique-owned.

模板参数
TNon-ECS object type stored in slots.
TagEmpty tag making the handle type domain-specific.

All methods are owner-thread-affine. resolve() returns Borrowed and never extends object lifetime. clear() and destruction invalidate every prior handle; a new registry instance receives a distinct owner epoch.
