template<class I , class F >
void eve::cap::forEach ( F &&  fn)

Call fn for every implementation of I in priority order.

Dispatch uses a snapshot of the listener pointers taken before the first callback. Registrations and withdrawals made by a callback affect later dispatches, but not the dispatch already in progress. A withdrawn listener must therefore remain alive until the current dispatch returns.
