13// ---------------------------------------------------------------------------
14// Engine-wide profiling core (Tracy / UE Insights style scoped zones).
15//
16// Any module may sprinkle scoped zones at its per-frame entry points:
17//
18// void World::update(float dt) {
19// EV_PROFILE_MODULE("physics", "World::update");
20// ...
21// }
22//
23// Zones are cheap when disabled (a single atomic branch); when enabled they
24// push {name, module, thread, start, end, parent} into a per-thread buffer and
25// frameMark() aggregates the frame into a call tree with self/total time per
26// module and per zone. This core lives in common/ so lower layers can use it
27// without violating the module layering rules.
28// ---------------------------------------------------------------------------
29
