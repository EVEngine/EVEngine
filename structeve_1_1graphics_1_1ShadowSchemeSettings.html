详细描述

Process-wide defaults for creating shadows per light family.

Controllers (RenderControl / script / PhotoMode) mutate this; RenderSystem3D and Graphics backends read it each frame when selecting casters, building CSM, and allocating/resizing the depth-array atlas.

Directional CSM and local spot shadows currently share one depth array, so resolvedAtlasMapSize() (max of the clamped directional/local sizes) is the GPU extent. Changing map size recreates shadow GPU resources on the next ensure/create path (@cost relative magnitude: full atlas realloc + deferred FrameGraph rebuild; amortized across frames until the next size change).

Local spot shadows use a fixed atlas (kLocalSlots). When more casters request shadows than slots, paging scores by intensity / distance / soft screen coverage and keeps sticky occupancy (hysteresis). An independent update budget can time-slice redraws while still sampling cached maps.

@thread Render thread only.
