Bake one wall with merged opening cavities and explicit reveal liners.

Overlapping openings are merged along the wall parameter before carving. Reveal primitives use *.reveal.* ids so hosts can distinguish cavity liners from structure. This is a parametric boolean (segment solids + reveal faces), not IFC/CSG BREP.

Rasterize one level into a grid for ortho/iso/HD2D hosts.

Floor cells come from Zone polygons; Wall from wall segments; Portal from openings and level portals. Orientation is recorded as metadata only — hosts apply map TileLayer projection separately.

参数
documentBorrowed authority.
levelIdLevel to rasterize.
cellSizeMetres per cell; must be finite and > 0.
orientationWire hint ("orthogonal" or "isometric").
返回
Grid on success; InvalidArgument when level/cellSize is invalid. @cost O(cells * regions + wall samples); amortize per document revision.

◆ importCellGrid()

EVENGINE_API_WORLD eve::Result< void > eve::archspace::importCellGrid ( Document &  document,
const std::string &  levelId,
const CellGridImport &  grid,
const std::string &  idPrefix = "cell" 
)

Import a dungeon/cave occupancy grid into an existing level.

Flood-fills Floor cells into Region zones (AABB polygons). Portal cells are bridges — they do not join regions during flood fill — and become Portal nodes when they touch two distinct Floor regions. Sets document topology to Dungeon when currently Architectural.

Does not depend on procgen / map; callers feed cells from any generator.

参数
documentMutated in place; on failure the previous state is restored.
levelIdExisting Level node id.
gridRow-major cells; size must equal width*height.
idPrefixPrefix for generated region/portal ids (non-empty).
返回
Applied on success; InvalidArgument/NotFound on bad input. @cost O(cells) flood fill + portal scan; amortize per imported layout.
