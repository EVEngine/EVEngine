详细描述

Runtime/editor-neutral session that turns an input trail into mesh geometry.

The session is synchronous, owner-thread-only, and retains only copied point values. Callers own input timing and raycasting. Mutations increment a monotonic revision and failures leave the point sequence unchanged.
