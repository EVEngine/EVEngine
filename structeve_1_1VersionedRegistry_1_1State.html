详细描述

template<class Key, class Value, class EventData = std::monostate, class Compare = std::less<Key>>
struct eve::VersionedRegistry< Key, Value, EventData, Compare >::State

Owning state image used for transactional snapshot/restore.

Entries include tombstones. Restoring this image never emits individual subscription callbacks; callers re-query after a successful restore.
