详细描述

Immutable owning per-source terrain write plan prepared from one authoritative network snapshot. Owner-thread only, synchronous. No network, mesh or provider pointers survive preparation. Applying borrows the destination until return and publishes one undo frame; failures leave it unchanged. Shared junction/derived geometry uses the explicit shared policy, never an inferred incident-edge winner.
