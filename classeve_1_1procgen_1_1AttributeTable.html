详细描述

Schema-bearing column store aligned with a PointSet's point rows.

Attribute names are interned once per table and each name owns exactly one typed column. Missing values occupy an empty optional slot instead of allocating a map per point. The table is an owning value, is not thread-safe for mutation, and invalidates borrowed column storage after any schema or row-count mutation.
