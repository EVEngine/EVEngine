详细描述

Type-erased bookkeeping shared by every RuntimeInstance<State>.

Identity validation, the active flag, the reload policy machine and the error construction are identical for every domain state, so they live in one non-template core compiled once in DefinitionRuntime.cpp instead of being instantiated once per state type.

The payload stays strongly typed at the public API: this core only carries it as an owning pointer plus the per-state clone/assign/destroy operations. It is never turned into a dynamic field map.

Thread affinity matches RuntimeInstance: the owning domain thread only.
