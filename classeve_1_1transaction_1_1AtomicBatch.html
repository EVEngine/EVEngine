详细描述

Single-use composition of domain participants and one payer's costs. Owns staged participants, never game state. Domain producers add independent effects; payment is merged and committed once through the existing coordinator. Script bindings retain each domain facade until commit/destruction. Entity participants must revalidate handles at prepare/commit. VM owners must outlive this batch; all calls run on the same VM/simulation owner thread without reentry. No script callbacks run during commit. This transient builder is not serializable.
