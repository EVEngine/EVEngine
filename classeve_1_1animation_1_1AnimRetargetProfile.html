class AnimClip
 

详细描述

Settings and diagnostics for offline skeletal animation retargeting.

Explicit bone mappings take precedence over automatic matching. Automatic matching first tries the exact name, then a normalized name with namespaces, punctuation and case removed (for example mixamorig:Hips matches hips). Script type: AnimRetargetProfile.
