详细描述

Domain-neutral input to one settlement operation.

magnitude is the requested positive amount before source modifiers. context is an owned canonical Value and must contain only serializable data. tick is supplied by the simulation owner; the pipeline never reads wall-clock time. Causation and correlation are optional canonical event metadata and are copied to the result event.
