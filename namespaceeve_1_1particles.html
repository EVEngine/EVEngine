EVENGINE_API_DOMAINS Result< physics::ParticleTrack > eve::particles::buildParticleTrack ( PersistentId  emitterSession,
float  duration,
std::span< const particles::ParticleRecordEvent >  events,
const physics::BakeRecipe &  recipe 
)

Convert a completed emitter-session journal to an immutable planar particle track. @ownership Borrows events and recipe only during conversion; result owns all values and survives source destruction. @thread Inputs must remain stable; no callbacks, simulation, ECS or resource lookups.

备注
Same-time snapshots replace earlier snapshots for that birth (post-inheritance appearance wins). Every birth must have one terminal death; zero-duration births are validated then omitted as never visible. Distinct times that collapse to one float are rejected, rather than silently losing event boundaries. @cost Linear in event count plus logarithmic birth lookup; allocates once per completed recording outside playback.
返回
Complete track or invalid event order, missing death, duplicate lifetime, budget or provenance diagnostic.
