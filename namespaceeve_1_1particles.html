GPU-accelerated integration step; false = unavailable, caller falls back to CPU.

GPU-accelerated variant of stepEmitterSim. The per-particle integration loop runs in a compute shader; spawning / death compaction / collision stay on the CPU. Returns false when the GPU path is unavailable — the caller then falls back to stepEmitterSim.

◆ kParticleGpuKernel

const char* eve::particles::kParticleGpuKernel
inline

GLSL compute kernel for GPU-accelerated particle integration.

Particle layout: 16 floats per particle. [0] x, [1] y, [2] vx, [3] vy, [4] life, [5] lifetime, [6] size, [7] rot, [8] spin, [9] frame, [10] radial, [11] tangential, [12] ax0, [13] ay0, [14] noisePhase, [15] pad

Push constants (float[32]): [0] aliveCount, [1] dt, [2] emitterX, [3] emitterY, [4] gravityX, [5] gravityY, [6] damping, [7] limitVelocity, [8] noiseStrength, [9] noiseFrequency, [10] noiseSpeed, [11] time, [12] frameRate

Compile with glslc (Vulkan SDK) — the engine also compiles this at runtime via Gpgpu::newShader when the first GPU emitter initializes.
