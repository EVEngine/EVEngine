详细描述

Bounded, caller-fed PCM playback, independent of codecs and synthesis. @ownership Caller owns this object; submitted samples are copied synchronously. @lifetime Audio teardown closes outstanding streams before destroying OpenAL. Destruction of this object releases playback even while Audio remains alive. @thread All operations and destruction run on Audio's owning/main thread. @reentrancy Never invokes scripts or user callbacks. Not concurrently callable. Streams are transient: hot reload must close/recreate them, not serialize them.

◆ submit()

Result< int > eve::audio::PcmStream::submit ( std::span< const float >  samples)

Copy interleaved normalized samples and queue one block atomically.

参数
samplesBorrowed for this call only; finite values in [-1,1], nonempty, channel-aligned, at most maxBlockFrames frames. Stereo is L,R,L,R.
返回
Accepted frame count; Conflict on full queue, PreconditionViolation after finishInput/close, InvalidArgument on invalid samples. Rejection queues nothing. @cost Linear in submitted samples, bounded to one block; conversion/copy is amortized per block, never per script callback on the audio thread.
