详细描述

Solver-independent control of one constraint, owned exclusively by its Joint3D facade. @ownership The implementation owns the native constraint until destroy or parent invalidation. @lifetime No native identifier escapes; invalidate detaches before parent body/world teardown. @thread All calls run on the owning simulation thread, between steps. @reentrancy Calls never invoke user callbacks. Setters validate all inputs before mutation.

备注
Results report StaleHandle, InvalidArgument, or Unsupported without partial mutation. Reads return owning values. Implementations must not emulate unsupported features silently.
