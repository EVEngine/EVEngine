详细描述

A virtual-geometry renderer: preprocesses a mesh into a cluster DAG, uploads it to the GPU, then each frame runs GPU-driven culling + a software rasterizer into a visibility buffer.

Lifecycle (Squirrel): r <- vg.newRenderer() r.buildIcosphere(4) (or build(...) with raw arrays) r.setViewport(w, h, fovYDeg, errorPx) r.setCamera(view[16], proj[16], model[16], cam[3]) visible <- r.update() ok <- r.resolve(rgbaArray, w, h) // CPU readback of the visibility buffer
