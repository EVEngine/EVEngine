◆ expose() [1/2]

void eve::ModuleManager::expose ( Runtime &  runtime)
static

Installs the eve table and defers native class method bindings.

Result helpers and script ECS are bound immediately. Each module's expose(ssq::Table&) (class + methods + nested types) runs on the first script get of that class name, or of a nested class it owns. The default unfiltered startup path eagerly completes all bindings while preserving the canonical script ECS object identities.
