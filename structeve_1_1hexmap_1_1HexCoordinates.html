详细描述

Axial coordinates of one hex cell.

The third cube component is derived: y = -x - z. The map uses the odd-row-offset-right layout of the reference hex-map project, so the axial pair is directly the (column, row) pair with even rows starting at column 0 and odd rows shifted half a cell to the right.

◆ toWorldPosition()

static HexVec3 eve::hexmap::HexCoordinates::toWorldPosition ( HexCoordinates  coordinates)
inlinestaticnoexcept

World-space centre of a cell before elevation and perturbation.

The odd-row offset of an axial pair is x + z/2, so the reference layout (offsetX + (z odd ? 0.5 : 0)) * innerDiameter collapses to (x + 0.5 * z) * innerDiameter and the result is the exact inverse of fromWorldPosition.

参数
coordinatesCell coordinates.
返回
Centre position on the XZ plane; Y is always 0.
