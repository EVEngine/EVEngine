详细描述

Immutable connectivity and UV ownership for fixed-topology deformation playback. @ownership Copies share frozen value storage; vertex indices define stable identities within this topology. @lifetime Spans borrow this topology's shared storage and expire when its final owning copy is destroyed. @thread Const access is reentrant; preparation retains no source pointers, solver, GPU objects or callbacks.

备注
A changed index order, winding, vertex count or UV produces a different topology identity.
