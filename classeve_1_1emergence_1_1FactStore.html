详细描述

Mutable fact bag that doubles as a read-only Condition evaluation context.

FactStore is the sole owner of rule-visible values. Mutations report whether the stored value changed so the RuleEngine can wake only interested watchers.

@thread Owning simulation thread only; no synchronization is performed. @reentrancy Does not invoke callbacks.
