详细描述

CPU-side decal registry: spawn / remove / fade / quotas, and the per-frame drawer that feeds the graphics decal pass.

Rendering path: DecalManager registers a RenderSystem3D::DecalExtraDrawer, which runs between the G-buffer and the forward pass. For each visible instance it builds the box transform (Z axis = surface normal, optional random yaw) and calls gfx.drawDecal.
