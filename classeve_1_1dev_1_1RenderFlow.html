详细描述

Render-pipeline flow tracer with a Weiser-style backward slice.

Models pass nesting + bind→draw resource data-flow so a Graphics exception can be attributed to the active pass and the resources that fed the draw.

Event storage is a fixed ring buffer: when full, new events overwrite the oldest slot in place (O(1)).
