class ActionRuntime
 

详细描述

Read-only view of one execution owned by ActionRuntime.

Adapters receive no mutable lifecycle fields and must not create a second timer or phase machine. The optional receipt is an audit value; the resource provider/account remains authoritative for resource state. A reservation is never retained across an action phase or frame.
