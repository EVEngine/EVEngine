详细描述

Immutable schema/route catalogue built transactionally from compiled families. @ownership Owns schema strings and tool-name keys; function pointers remain binary-owned. @lifetime Immutable until destruction; not a plugin/unload registration mechanism. @thread Construction is caller-owned; concurrent const reads are safe afterward. @reentrancy Schema callbacks run without locks and must not request this catalogue while it is building.
