详细描述

Spatial index module — broad-phase / map culling structures. Script: spatial <- eve.Spatial();

Provides 2D/3D QuadTree, Octree, SpatialHash, and BSP (kd-style) factories. No overloads: use distinct *2D / *3D type names.
