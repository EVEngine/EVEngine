详细描述

CPU geometry builder for A-to-B selection indicators, independent of object lifetime. @ownership Caller owns the builder and returned meshes; all inputs are copied values. @thread Owner-thread mutations; independent instances can run concurrently. No callbacks. Geometry is transient, deterministic within floating-point tolerance (1e-5 relative). Target resolution, visibility, material, depth testing and upload belong to the caller.

Result< MeshBuild > eve::procgen::ArrowGenerator::buildMeshResult ( ) const

Build a new owning mesh without changing this builder or any previously built mesh.

返回
InvalidArgument for a reversed curve, a non-XY 2d path, or a path too short for the head. The head tip is exactly B in every mode; flat geometry tapers width and thickness to one geometric apex. Shaft starts at A. Tube/ribbon UV u follows normalized sampled arc length; flat UVs are per face. @cost Tube/ribbon CPU work is linear in curve segments times radial sides. Flat bevels use quadratic contour validation and up to cubic cap triangulation in contour vertices; reuse the mesh until endpoints or style change, and coalesce pointer updates before building/uploading.
