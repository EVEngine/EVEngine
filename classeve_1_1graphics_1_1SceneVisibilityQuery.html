详细描述

Single-use, owning visibility request; no ECS/resource pointer survives a call. @thread Prepare and measure on the engine owner thread. No callbacks. @lifetime Query owns protocol values; Graphics is borrowed only during measure.

◆ measure()

Result< Value > eve::graphics::SceneVisibilityQuery::measure ( Graphics &  graphics)

Consume the request, resolve current generation-qualified meshes and capture private GPU targets. @cost Blocking GPU raster/readback of one scene pass plus one isolated pass per unique target object, per candidate. CPU isolated-mask intersections are quadratic in target count and linear in viewport pixels.

返回
Owning v3 evidence including depth-independent directed projected overlaps, or explicit unsupported/stale/budget diagnostic; never edits live transforms.
