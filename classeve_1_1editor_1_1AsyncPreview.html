详细描述

template<class Payload>
class eve::editor::AsyncPreview< Payload >

Typed latest-request preview publication using the existing editing task executor. @ownership Worker owns immutable input captures and a private completion mailbox, never a domain pointer. @thread All methods are owner-thread only. Work runs on TaskService's worker and must cooperate with cancellation. @reentrancy No work or unknown callback executes under a publication lock. @lifetime Close invalidates publication immediately; destruction cancels and joins bounded/cooperative work.
