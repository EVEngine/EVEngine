详细描述

Fog-of-war bookkeeping: how many viewers currently see each cell.

Visibility is a counter, not a flag, because several actors overlap: a cell stops being visible only when the last viewer that covered it stops looking. The first time a cell becomes visible it is also marked explored, which is a one-way latch: explored cells stay explored after the viewer leaves and only the visibility counter drops.

Invariant: counts_[i] == 0 for every cell that no viewer covers, and counts_[i] > 0 exactly for the cells isVisible(i) reports.

Ownership and lifetime: owns one counter per cell; reset re-sizes it and clear zeroes it. It does not own the map it annotates.

Thread affinity: main thread only; no locking.
