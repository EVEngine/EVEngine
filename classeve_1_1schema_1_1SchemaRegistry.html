◆ find()

const SchemaDefinition * eve::schema::SchemaRegistry::find ( const std::string &  id)
static

Finds the highest registered version for an id, or nullptr.

This is the legacy id-only resolution rule. Use resolve() when the caller has a persisted schema version and must not silently select a newer definition.

返回
Borrowed nullable schema definition owned by the registry. @ownership SchemaRegistry owns the entry; callers must not delete or mutate it. @lifetime Valid until any registry mutation or destruction; copy data before registering another version. @thread Call on the schema registry thread. @reentrancy The lookup invokes no callbacks and is invalid across re-entrant mutation.

Registers one explicit forward migration edge.

参数

fromVersionExact source version.
toVersionExact target version; it must be greater than source.
migrationPure function returning a new owning payload.
