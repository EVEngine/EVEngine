详细描述

Owned generic mesh LOD output generated with Pcg's independent-per-level policy.

Every generated level is simplified from the same immutable source mesh, matching LODGenerator.CreateLevelRenderer; levels are not simplified sequentially. The set owns all CPU meshes and values and is safe to move. Callers serialize access.
