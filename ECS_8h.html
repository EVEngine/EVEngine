using eve::CppEntityViewFn = std::function< void(ssq::Array &out)>
 C++ 实体 → 脚本 eve.view() 桥接。 用 registerCppEntityView(cls, fn) 登记脚本类的收集函数； 脚本 eve.view(cls) 沿类链找到登记的 C++ 类型后调用 fn 填充输出数组。
 
using eve::PostEcsHook = std::function< void(ssq::Table &table)>
 在脚本 ECS 基类（eve.Component / eve.Entity / eve.System）注入之后执行的回调。 模块用它注入"extends eve.Entity"的脚本基类（例如 eve.SceneEntity）。 在 exposeECS / exposeECSToVM 末尾运行，早于任何游戏脚本。
