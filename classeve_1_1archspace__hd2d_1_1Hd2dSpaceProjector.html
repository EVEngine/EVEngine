详细描述

Projects an ArchSpace level onto a TileLayer and HD-2D TileMap3D bake path.

Sync rebuilds the shared grid → TileLayer via TileMapProjector. Mesh upload is deferred: call buildMesh / buildRenderable when a Graphics host is available. Unit tests can assert TileLayer GIDs without opening a GPU window.

@ownership Owns its TileMapProjector (and thus an owned TileLayer unless setLayer was used on tiles()). TileMap3D is value-owned configuration only. @thread Owner thread only.
