# 日常材质参考对照与质量整改

本轮以 `docs/images/procgen-materials/reference-spheres.png` 为目标，逐项检查真实
NVIDIA Vulkan 材质球，而不是把截图成功当作材质验收通过。

| 问题 | 代码原因 | 本轮调整 |
| --- | --- | --- |
| 木纹像等距条纹、塑料感重 | 单方向正弦条纹，缺少生长环与导管；表面过亮 | 弯曲生长环、纵向不规则导管、独立色素和浅浮雕，提高默认粗糙度 |
| 钢、铝、拉丝金属近似同一材质 | 共用同一个拉丝采样分支 | 钢采用低粗糙度抛光；金属和铝分别调节细槽幅度与反照率 |
| 布料像粗网格 | 织纹重复单元太大、交织关系不明确 | 加密圆润纱线，交替经纬遮挡，叠加细纤维 |
| 纸像光滑塑料 | 原实现只有噪声，没有纤维几何分布 | 随机方向、位置与长度的短纤维；弱高度差与哑光表面 |
| 水泥和铸铁像均匀打孔 | 两者共用同一孔洞算法 | 水泥大小孔洞与斑驳砂浆；铸铁采用粗粒铸造表皮与不规则蚀坑 |
| 大理石像裂纹蛋壳 | 等宽闭合胞元边界，底色几乎没有云雾变化 | 多尺度扭曲、断续色脉、柔和矿物晕染；保留近乎平整的高度 |
| 钢没有镜面环境内容 | 原环境只有两块灯板 | 增加统一摄影棚墙面、窗格和地面环境；所有球使用同一环境 |
| 底座条带异常 | 底座与球体走不同材质路径 | 底座统一为 glTF PBR，侧面与端面分离法线 |
| 玻璃没有可辨认透射 | 通用材质仅有 transmission/ior 元数据；预览背景缺少可见结构 | 球体专用预览计算入射/出射折射、菲涅耳、吸收，以及已知底座交点 |

公共生成器 API、贴图所有权和共享六通道流水线保持一致；本轮修改集中在内部
采样、材质默认值和可复现展示场景。随机输入仍由 seed 决定，颜色与高度独立。
新增跨两条 UV 接缝的连续性检查，同时覆盖低分辨率下的奇数采样带宽。

## 验证边界

- CPU 测试检验确定性、参数边界、物理通道、脚本光学元数据与纹理接缝，不替代视觉验收。
- 实际帧通过引擎 MCP 截取，设备必须为 NVIDIA discrete；软件设备会被场景拒绝。
- CPU 生成器与着色器使用本工作区源码，运行宿主使用已有缓存引擎；这不是当前整个引擎重新编译或 Linux Release 重新发布的证据。
- `RenderSystem3D::renderToCanvas` 明确不执行 shadow/G-buffer/AO pass，故接触阴影仍缺失。
- 球体玻璃探针只适用于单位球和已知摄影棚底座，不代表任意模型的厚度/背面/透射已接入通用 PBR。
- 当前木纹形态、金属微划痕、矿物色层与参考仍有差距。参考图是 AI 目标图，没有配套 HDRI、BRDF、几何和相机参数，不能宣称已完成像素级还原。

架构规则方面，本轮没有新公开 API、持久格式、模块依赖或跨域生命周期；继续遵循现有
Result/所有权、确定性与模块契约。无主动豁免。源门禁需分别说明 `HEAD` 增量与
默认 `origin/dev` 基线结果。

本轮最终 CPU 回归：7 项、57,258 条断言通过。默认 `make check` 在跨 `origin/dev`
的历史差异中报出 71 个架构契约问题；没有添加基线或白名单来屏蔽它们。
增量门禁另以 `make check CI_BASE=HEAD` 检查，并使用临时 Git 索引纳入新增文件，
不改变用户暂存区。最终帧设备为 RTX 3090，驱动 595.99.02。

## 第二轮：固定场景与结构模型整改

- scale 与分辨率解耦；低分辨率做四点预过滤，不改变结构数量。
- 木纹的生长环宽度与色调由种子控制，导管沿同一变形生长坐标分布；展示中取消木材清漆层。
- 金属/铝采用不同频率和幅度的细槽，降低反照率条带对高光的干扰。
- 大理石移除胞元边界主纹路，采用矿物浓度轮廓、次级脉络、云雾色层及专用矿物色带；高度仍接近平整。
- 玻璃用实际不透明场景的颜色和 RGB24 视深，追踪出射光线；不再用无关窗格环境作为透射背景。
- 自定义着色器只读取当前源码与缓存宿主一致的 Frame 参数前缀，避免灯光数组布局差异；透视 clip.w 提供视深。
- 固定背景、灯光、相机、1024 贴图、几何和涂层。修改前后只更换生成贴图和玻璃实现；AI 参考仍不是同一摄影棚的物理基准。
- 底座加入当前单位球场景专用的解析遮蔽与软阴影，不代表引擎通用阴影或玻璃焦散已完成。

新增分辨率一致性 CPU 测试和着色器源码/SPIR-V ABI 契约测试。8 项 CPU 测试、
73,694 条断言在 ASan/UBSan 下通过。所有新图仍使用 RTX 3090、NVIDIA ICD 和引擎 MCP 截图。
公共 API 形状、Result/贴图所有权、模块依赖不变；无架构豁免。通用体积透射与焦散仍未实现。

## 光斑间距调整

主灯板方向改为 (-0.65, 0.70, 0.35)，补光移至侧后方 (0.95, 0.25, -0.15)。
补光水平半宽从 0.10 收到 0.04，能量从 0.55 降到 0.22；主方向光与主灯板同向，
其能量从 1.6 降到 1.2，减少同方向高光叠加。材质、相机和几何保持同一版本；
91 张材质 PNG（含 ORM）逐文件哈希一致。RTX 3090 实际截图确认右侧高光向轮廓移动，
呈现更细的边缘亮带。相关 Python 检查与 git diff --check 通过。

## 日常表面结构与环境盒

这轮先排查贴图与绑定：paint、cast iron、cloth 原本都有 normalTexture，
但 paint 高度值只有 126–129，默认纹理幅度不足；球面 UV 还把细节横向拉长。
现在独立调整高度与粗糙度，并修正球面纹理比例，油漆清漆层也绑定同一法线。

- Paint：独立橘皮结构，适量提高粗糙度，避免颜色噪声充当法线。
- Cast iron：多尺度铸造颗粒与凸起，增加法线幅度和粗糙度。
- Cement：以双向起伏的骨料为主，减少密集下凹孔洞；高度高于 128 和低于 127 的像素分别约 47% 和 49%。
- Cloth：默认经纬密度从 72 降为 40，增强交织纱线的凸凹；降低展示材质的镜面权重。
- Rubber：增大表面颗粒、提高粗糙度，降低展示材质的镜面权重，使漫反射更明显。
- Marble：改为周期连续的流动主脉、有限长度分叉和云状底色，增强颜色层次；石纹仍不直接变为深沟法线。
- Glass：降低过强吸收，保留双界面折射；六面真实环境盒的窗框和地板可以辨认其透射、折射与反射。

环境盒先由 reflection probe 捕获并过滤，再用于所有球体的环境反射；
墙体 capture mask 为 1，球和底座为 2，避免球体自捕获。环境边界统一传给玻璃盒投影。
