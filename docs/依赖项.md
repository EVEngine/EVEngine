
squirrel - 核心脚本语言
simplesquireel - squirrel的C++绑定
VkBuilder - 最新写的整合了vkbootstrap和Vookoo两个库一些特性的vulkan操作封装
ECS.hpp - Class-enabled ECS（[sunxfancy/ECS.hpp](https://github.com/sunxfancy/ECS.hpp)），本仓库以 git submodule 置于 `external/ECS.hpp`；替换未完成的自研 ECS，供声明式渲染与游戏实体使用
zeroerr - 单元测试 / 断言 / 日志（git submodule：`external/zeroerr`；ECS.hpp 测试头不在本迁移范围）
poco - 用来支持网络访问、数据库、文件系统的watch操作
medialoader - 把love引擎中的图像载入跟声音载入单独扒下来的一个库，方便单独使用
    - 这里还有好几个其他类库用来载入图像跟音频
SDL2 - 核心窗口、消息、各种input
freetype - 字体
glm - 核心数学库
imgui - 基础图像gui
openal - 用来实现3d立体声
physfs - love使用的文件系统，这里也抄来用做文件系统
Box2D - 物理引擎
lz4、zlib - love用来压缩数据用的，先拿过来，看看需不需要
smmalloc - 用来优化内存分配和实现snapshot的内存分配器
CLI11 - 命令行解析
rang - 命令行彩色输出
