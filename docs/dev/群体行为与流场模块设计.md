# 群体行为与流场模块设计（Crowd）

> 状态：设计草案（一期：CPU 连续流场 + 海量单位转向/行动 + Boids）。
> 日期：2026-08-23
> 目标：为 EVEngine 提供一套**纯仿真、与渲染解耦**的群体行为模块：
> 连续流场寻路（Flow Field）、海量集群单位的移动 / 转向 / 行动，以及
> Reynolds Boids 鸟群聚合算法，统一暴露给 Squirrel 脚本。
>
> 关联：[寻路系统设计.md](./寻路系统设计.md)（map 的格级 Flow Field）、
> [空间索引模块设计.md](./空间索引模块设计.md)、[模块编排与裁剪架构.md](./模块编排与裁剪架构.md)。

## 1. 需求拆解

`map` 模块已有的寻路是**格级**的：`FlowField` 每格存「下一步指向哪个邻居」，
`followFlow` 得到一串格子路径。它解决了「N 个单位同目标」的寻路复用问题，
但单位落地时仍缺少连续移动层：

| 需求 | map FlowField | crowd 模块（本期） |
|------|--------------|-------------------|
| 多单位共享一次寻路 | ✅ 目标反向 Dijkstra | ✅ 复用 |
| 连续位置跟随（格子内平滑移动） | ❌ 只有格跳转 | ✅ 逐格梯度 → 连续方向向量，双线性采样 |
| 单位间避让 / 群体形态 | ❌ | ✅ 分离 / 对齐 / 聚合（Boids 转向力） |
| 平滑转向（限转角速率） | ❌ | ✅ `turnRate` 限制每帧最大转角 |
| 行动状态（idle / 跟随流场 / 寻点 / 鸟群） | ❌ | ✅ 每单位 action + data 标记 |
| 海量（万级）单位 | — | ✅ SOA 存储 + 计数排序空间网格 |

一期**非目标**：

- RVO / ORCA 硬约束避障（一期用软分离 + 可选的位移消解；接口预留权重）
- GPU / 多线程并行（SOA 布局已按并行友好设计，二期可加 job 化）
- NavMesh（栅格流场已覆盖 2D 俯视 / 塔防 / RTS 的主要场景）
- 3D 高度场 / 飞行三维 flocking（本期 2D 平面）

## 2. 总体架构

```text
eve.Crowd  (模块门面, SLOT=crowd)
  ├─ CrowdField       连续流场（Dijkstra 积分场 + 梯度方向场 + 双线性采样）
  │     resize / setBlocked / setCellCost / setGoal(s) / build
  │     flowAtWorld / costAtWorld / flowAtCell
  └─ CrowdSim (Impl)  SOA 单位仿真
        ├─ AgentState  x, y, heading, vx, vy, speed, radius,
        │              maxSpeed, maxAccel, turnRate, action, data
        ├─ 空间网格     计数排序（count + prefix-sum + scatter），每帧 O(N)
        ├─ steering     Boids 三力（separation / alignment / cohesion）
        │              + 流场跟随 / 寻点 arrive / wander
        ├─ 转向         heading 以 turnRate·dt 为上限向速度方向收敛
        └─ 消解         （可选）1 次位置分离 pass，缓解目标点拥堵
```

## 3. CrowdField：从「下一格」到「连续方向」

### 3.1 数据结构

```text
CrowdField {
  width, height         格子数
  cellSize              世界单位 / 格
  originX, originY      世界原点（格子 (0,0) 中心）
  cost[]                地形代价：0 = 阻挡，>=1 可走（进入该格的成本）
  integ[]               Dijkstra 积分场：到目标的最小代价（inf = 不可达）
  flowX[], flowY[]      每格单位方向向量（沿代价下降方向 = -∇integ）
  goals[]               目标格集合（build 时全部以代价 0 入队）
}
```

### 3.2 建场（Dijkstra）

- 从所有 `goals` 以 `integ = 0` 入队，8 邻域扩展；正交边代价 1，对角边代价 √2，
  进入邻格再乘该格 `cost[]`。
- `cost[] <= 0` 的格不扩展也不可达。
- 单目标快捷入口 `buildFlowField(gx, gy)` = `clearGoals + addGoal + build`。

### 3.3 梯度方向场

每格用**中心差分**近似 ∇integ，方向取负（朝代价下降）：

```text
gx = (integ[left]  - integ[right]) / (2·cellSize)
gy = (integ[top]   - integ[bottom]) / (2·cellSize)
flow = normalize(-∇integ)，仅统计可达的相邻格；全不可达则 flow = 0
```

目标格 `integ == 0` 时 flow = 0（已到达，不需要方向）。

### 3.4 连续采样

- `flowAtWorld(x, y)`：世界坐标 → 格子坐标，取周围 2×2 格做**双线性插值**后归一化；
  不可达格按 0 方向处理，整格场外返回 0。
- `costAtWorld(x, y)`：双线性插值积分代价；只有角落全不可达才返回 inf
  （避免单位在可达区边缘被"吓停"）。

复杂度：建场 O(W·H·log)，每单位每帧采样 O(1)。万级单位共享一次建场，
这正是流场相对逐单位 A\* 的核心收益。

## 4. CrowdSim：海量单位的移动、转向与行动

### 4.1 SOA 存储

所有单位状态按字段分列存放（`vector<float>` / `vector<int32_t>`），热循环按列遍历，
缓存友好；`action` 用 `int32_t` 枚举而非字符串，脚本层做字符串 ↔ 枚举映射。
单位 id = 槽位索引，`removeAgent` 用 swap-pop O(1)（与粒子一致：删除后 id 不稳定）。

### 4.2 空间网格（每帧重建）

```text
pass 1  求包围盒（向外扩 sepRadius）
pass 2  每格计数
pass 3  前缀和 → cellStart，scatter 到 sorted[]
```

查询取 3×3 邻域格，直接线性扫描候选，无堆分配。O(N + 格数 + 查询邻域)。
网格单元取 `max(sepRadius, perceiveRadius)`；一次查询同时供三种力使用，
分离只对 `d ≤ sepRadius` 生效，对齐/聚合对 `d ≤ perceiveRadius` 生效。

### 4.3 转向力合成（每单位每帧）

```text
desired = base(action) + separation·sepWeight
          + alignment·alignWeight + cohesion·cohesionWeight
          + wander（boids 可选）
```

| action | base | 说明 |
|--------|------|------|
| `idle` | 0 | 不主动移动，分离力仍可推开（排队 / 围观） |
| `flow` | 流场方向 · maxSpeed | 大部队沿流场行军，分离力防扎堆 |
| `seek` | normalize(目标-自身) · maxSpeed，进入 arriveRadius 线性减速 | 单兵 / 英雄寻点 |
| `boids` | 0 + 可选目标偏置 / wander | 纯鸟群：聚合 + 对齐 + 分离 |

然后：

```text
accel = clamp(desired - vel, maxAccel·dt)
vel  += accel；speed = |vel|；if speed > maxSpeed 缩放
targetAng = atan2(vy, vx)
delta = wrapPi(targetAng - heading)
heading += clamp(delta, -turnRate·dt, +turnRate·dt)   // ← 转向
x += vx·dt；y += vy·dt
```

移动方向用 `vel`，`heading` 只做朝向（供渲染旋转、攻击方向、行动判定），
二者解耦正是"转向"与"位移"分离的表现；`turnRate` 决定转弯的圆滑程度。

### 4.4 位置消解（可选）

目标点拥堵时速度分离已接近静平衡，但仍有少量重叠：
`resolveOverlaps=true` 时做 1 次位移 pass：对 sepRadius 内实际重叠
`d < radiusA + radiusB` 的对，按重叠量各推开一半。默认开启，可关。

### 4.5 墙体碰撞（必须）

流场只负责"引导"，不负责"约束"：单位被拥挤/转向力推进阻挡格后，
没有任何机制会把它推出来——视觉上就会"穿墙卡在墙里"。因此 `step()`
末尾固定执行一轮**圆 vs 阻挡格碰撞消解**（`CrowdField::resolvePenetration`）：
按单位半径展开 AABB，检查覆盖到的格，对每个阻挡格沿穿透最小的轴把单位
推出（墙角处迭代 2 次）。保证任意时刻单位不会停在阻挡格内；
`clampToField` 只负责场边界，墙体消解负责场内障碍。

### 4.5 行动（action）扩展

- 每单位 `data`（int32）留给游戏自定义标记（兵种 / 阶段 / 目标 id）。
- action 字符串 ↔ 枚举在绑定层映射：`"idle" | "flow" | "seek" | "boids"`。
- 每帧批量读取 `getPositions(xs, ys)` / `getHeadings(hs)`（脚本预分配数组），
  渲染与游戏逻辑不需要逐单位回调（万级时逐单位 Squirrel 回调不可接受）。

## 5. 脚本 API（一期）

```squirrel
local crowd = eve.Crowd();

// ---- 流场 ----
crowd.resizeField(64, 48, 16.0, 0.0, 0.0);   // w,h,cellSize,originX,originY
crowd.setBlocked(cx, cy, true);              // 障碍
crowd.setCellCost(cx, cy, 2.0);              // 沼泽/山路代价
crowd.buildFlowField(60, 40);                // 单目标 + Dijkstra
// crowd.addFlowGoal(x, y); crowd.clearFlowGoals(); crowd.build();  // 多目标
local f = crowd.flowAtWorld(wx, wy);         // {x=, y=} 单位方向
local c = crowd.costAtWorld(wx, wy);         // 到目标代价

// ---- 单位 ----
local id = crowd.addAgent(100, 200, 0.0, 6.0);   // x,y,heading,radius
crowd.setAgentAction(id, "flow");                // idle|flow|seek|boids
crowd.setAgentTarget(id, 500, 300);              // seek/boids 目标偏置
crowd.setAgentSpeed(id, 120.0);
crowd.setAgentTurnRate(id, 4.0);                 // rad/s
crowd.setAgentData(id, 7);

// ---- 群体参数（Boids 权重）----
crowd.setSeparationRadius(24.0);
crowd.setPerceptionRadius(64.0);   // 对齐/聚合感知半径（Boids）
crowd.setSeparationWeight(1.0);
crowd.setAlignmentWeight(0.8);
crowd.setCohesionWeight(0.5);
crowd.setWanderWeight(0.2);

// ---- 每帧 ----
crowd.step(dt);
local xs = array(crowd.getAgentCount());
local ys = array(crowd.getAgentCount());
local hs = array(crowd.getAgentCount());
crowd.getPositions(xs, ys);
crowd.getHeadings(hs);
```

## 6. 示例与测试

- `examples/crowd`：2D 俯视演示——障碍流场 + 3000 单位行军 / 转向；空格切换
  `flow` / `boids` / `seek` 三种行动；鼠标点选目标点重定向全场。
- `test/crowd.cpp`：
  - 流场正确性：积分代价单调递减、梯度指向目标、阻挡区不可达、双线性采样平滑
  - Boids：三力方向符号、聚合收敛（平均距离下降）、分离保持最小间距
  - 转向：`|Δheading| ≤ turnRate·dt`
  - 海量冒烟：10k 单位 step 一帧完成且不越界
- `test/crowd_script.cpp` + `test/crowd.nut`：脚本 API 往返（添加/删除/状态/批量数组）。
