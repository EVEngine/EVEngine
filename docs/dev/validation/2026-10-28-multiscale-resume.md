## 后续误差界研究入口

三维 Laplace 势的局部展开误差有专门分析：
[On the Approximation of Local Expansions of Laplace Potentials by the Fast Multipole Method](https://arxiv.org/abs/2008.00653)。
该论文处理局部展开目标与经典 Greengard–Rokhlin 界的关系，核类型与本实现同属
Laplace 势；但展开基、截断阶定义及梯度界必须逐项映射，不能直接把论文中的
势误差数字代入当前加速度预算。下一轮应先推导适用于当前 Cartesian M2L 的
严格梯度余项，再通过小样本直接求和、边界/混合深度与大规模准入复验。
核对正文后还须消除一个术语歧义：论文的 `acceleration error` 指 FMM
加速算法造成的**势值近似误差**，不是引力加速度向量（势的梯度）误差。
因此即使直接复用论文的势误差定理，也不足以满足当前
`absoluteAccelerationError` 接口契约；必须独立证明梯度界。

## 2026-10-30 有界并行球体准备

`SphereFrame::build` 对不少于 16384 个候选对象按连续下标划分，最多使用 16 个内部 CPU worker。各 worker 只读取调用期输入并写入不重叠的帧槽位、可见性字节和错误状态；合并按原输入顺序压实，返回第一个下标区间内的首个错误。任务全部完成后才返回成功帧；不接触图形 provider，不改变旧渲染路径和现有公开函数签名。工作量仍为 O(N)，临时可见性为 N 字节，保留的 packet 容量为 O(N)，准备阶段的 wall time 包含启动、join 和压实。小批量保持单线程。

Debug SHARED 构建与 `graphics.multiscale` 9/9 通过。原生测试增加 32768 候选、几乎全部裁剪、最后一项可见的绘制证明，以及两个区间同时失败时优先返回较早输入错误；原有批量更新和填充行测试继续通过。日志 `build/multiscale-parallel-packet-debug-build.log`、`build/multiscale-parallel-packet-tests.log`。

同一机器 Release OBJECT、1080p、百万独立且每帧移动的球体三轮 CPU 准备 P50 为 40.145、39.831、40.157 ms；上传 P50 为 26.408、26.069、26.546 ms；完整渲染循环 P50 为 71.711、71.510、72.693 ms。前一版对应 CPU 准备约 350–360 ms、循环约 386–405 ms。GPU 队列延迟采样不等于同帧 GPU 完成时间；此基准不含场求解、积分、碰撞和生成，因此仍不能满足百万状态 16.67 ms 整帧验收。原始日志 `build/multiscale-parallel-packet-update-1000000-{1,2,3}.log`。
