## 实现

[normalizeCellPosition](../../../src/modules/spatial/multiscale/CellPosition.h) 把局部偏移进位至
int64 分区地址，输出 [-0.5,0.5) 偏移。使用 modf 分开整数/小数，再通过无符号有序地址
进行可检查的进位；不先把绝对地址转为 double，也不使用会在 0.5 相邻值上舍入的 floor(x+0.5)。
有效输入的表示变换精确；不恢复调用方已丢失的输入精度。NaN/Inf 和地址溢出显式拒绝。

[FrameGraph](../../../src/modules/spatial/multiscale/FrameGraph.h) 拥有不可变静态参考系树，
变换为 `x_parent = translation + 2^exponent * x_local`。输入拓扑排序，根为恒等变换；
深度上限64、累计尺度指数 [-900,900]，建图显式设置节点预算。
定义复制后归一化，任何失败都不发布部分图。构建 O(F)，投影 O(depth)，同参考系为 O(1)。

运行身份使用既有 RuntimeObjectRegistry/RuntimeHandleRef，不新增平行身份系统。
句柄包含 slot、generation 和 owner epoch；旧图/外来图句柄被拒绝。
图移动转移身份，替换或销毁失效旧身份。句柄是值，不持有图，也不序列化为持久地址。
本切片采用完整不可变图替换，没有单帧修改拓扑或逐节点销毁入口。

投影先取消共同祖先，只将两条不同分支的平移和局部位置转换为指定输出单位。
逐项累计投影和求和舍入界，超出预算则拒绝，不以不准确的结果继续。
不同分支的大平移近似抵消可能被保守拒绝；目前没有任意精度补偿后端。
同参考系路径先作精确整数差，能保留巨大绝对地址上的微小相对位移。

## 兼容与剩余工作

仍属于默认关闭的 spatial_multiscale；没有改动旧 Transform、Scene、Camera、Physics
的接口、默认值或执行循环。六面边界只有直接 C++ 值 API 和强类型帧身份，无 ECS System、
事件、provider、脚本或 MCP 新入口。直接调用符合单 owner、已知实现、高频投影、原子结果的四轴选择。
适用规则为唯一 owner、显式 Result、生命周期/线程/成本契约与 DLL 导出；无批准例外。

尚未完成旋转参考系、非惯性力、参考系动态迁移、版本化保存恢复、Scene/刚体适配、
高精度离线全面参考、完整引擎裁剪/链接及旧场景回归。静态轴对齐树不能冒充这些能力。
