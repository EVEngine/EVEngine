# 骨骼动画能力差距与演进

本文以 Unity Mecanim、Unreal Animation Blueprint/IK Rig 和 Godot AnimationTree
的公开能力为参照，记录 EVEngine 的现状与后续优先级。目标不是复制编辑器 UI，
而是补齐可组合、可测试、可由 Squirrel 和未来编辑器共同驱动的运行时数据接口。

## 当前能力矩阵

| 能力 | EVEngine 状态 | 差距与下一步 | 优先级 |
|---|---|---|---|
| Clip、TRS 采样、压缩、Notify | 已有 | 缺少通用 float curve/attribute 通道 | P1 |
| Cross-fade、状态机、Blend Space、Additive、骨骼 Mask | 已有 | 缺少 Inertialization，快速切换仍可能产生速度突变 | P1 |
| Locomotion Sync | 已有 leader/follower、归一化同步和 Sync Marker 区间同步 | 后续增加按权重自动选 leader 与 marker 调试可视化 | P1 |
| Root Motion | 已有平移/旋转提取和 loop 补偿 | 缺少锁轴、Bake Into Pose、世界/局部应用策略 | P1 |
| Retargeting | 已有 Avatar 式映射、骨架空间 Bind 校正、Retarget Root 和诊断 | 缺少链式 IK、Stride Warping、Speed Planting | P1 |
| IK/约束 | 已有 Aim、Two Bone IK、Foot IK 和有序约束栈 | 缺少 Pole Vector、关节限制、多链 Full Body IK | P1 |
| Runtime Graph | 已有 clip/blend/additive/mask/one-shot/1D/2D Blend Space | 缺少 Pose Cache、曲线/属性传播、线程安全 update/evaluate 分离 | P1 |
| 大规模角色性能 | 已有骨骼 LOD、降频、批量并行求值和 GPU skinning | 缺少全局毫秒预算、重要度调度、降频帧间插值 | P2 |
| 调试与编辑 | 有数据级可编辑 clip API | 缺少 Pose Watch、骨架/轨迹/曲线可视化和性能统计 | P2 |
| 物理动画 | 有 ControlPose 二阶动态 | 缺少 ragdoll、physical animation 和 pose snapshot | P2 |

## 参照原则

- Unity Humanoid Avatar 证明骨骼语义映射应独立于具体模型命名：
  <https://docs.unity3d.com/2018.3/Documentation/Manual/AvatarCreationandSetup.html>
- Unreal Sync Groups 使用 leader/follower；存在共同 Sync Marker 时按标记区间进度同步，
  否则回退到时长同步：
  <https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-sync-groups-in-unreal-engine>
- Unreal Animation Curves 将与姿态同步的 float 数据用于 Morph Target、材质参数和 gameplay：
  <https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-curves-in-unreal-engine>
- Unreal Animation Budget Allocator 按重要度和固定毫秒预算动态选择降频、插值或停止求值：
  <https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-budget-allocator-in-unreal-engine>

## 建议实现顺序

1. Sync Marker（已完成）：先解决不同节奏 locomotion 混合时的脚步错相。
2. Float Curve/Attribute：让 Morph、材质、音效权重和 gameplay 参数随 Graph 一起传播。
3. Inertialization：以短历史估算骨骼速度，降低突发状态切换的视觉跳变。
4. Root Motion Policy：增加轴锁定、Bake Into Pose 和应用空间。
5. Retarget Chain IK：在 FK 重定向后增加链长度校正、Stride Warping 和脚底速度种植。
6. Animation Budget：建立跨角色重要度和毫秒预算调度，而不是仅由每个 Player 自行降频。

每一阶段都应同时更新 C++ API、Squirrel 绑定、EVA 持久化、模块文档和独立测试，
避免只在某个固定编辑器面板中实现能力。
