# 工厂模拟框架设计（GPU + 2D 先行）

状态：垂直切片已落地（`logistics` 模块 + `examples/factory`）。本文是架构契约，不是路线图估时。

## 目标

在 EVEngine 上做大规模流水线 / 合成 / 自动化：

1. **2D 格点为权威**，`layers` 预留多层 / 3D 主机扩展。
2. **物流权威在 CPU 确定性 SoA**（可回放）；GPU 负责位置解算与海量绘制。
3. **复用** `building`/`grid`（建造 UX）、`production`（定时队列）、`inventory`（背包事务）、`gpgpu`（compute），**不新建**第二套库存或物理货物流。

## 分层

```text
examples/factory (配方、胜负、摆线)
  → logistics (belt / item SoA / machine buffer / 内置 craft 或 Production 投影)
  → production / inventory / building / definitions / orders
  → grid / spatial
  → gpgpu + graphics (只读可视化)
  → ECS / Result / Time
```

短根：`Machine` 与 `BeltCell` 不是 RPGActor；物品不是每件一个 `ecs::Entity`。
跨域关系用 owner 字符串 / typed handle（`machineOwnerId` → Production owner）。

## 数据权威

| 事实 | 所有者 |
|---|---|
| 传送带方向与占用格 | `logistics` Cell 数组 |
| 在途物品位置/进度 | `logistics` Item SoA |
| 机器输入/输出缓冲计数 | `logistics` Machine |
| 合成耗时（切片） | `logistics` 内置计时；正式游戏可投影到 `production` |
| 玩家背包 / 科技 | `inventory` / `definitions` / 游戏脚本 |
| 像素位置与 tint | `gpgpu` 从 sim floats 派生，可丢弃 |

## GPU 策略

1. **权威步进永不在 GPU**（订单、堵塞、合成结算要确定性）。
2. 每帧或按 dirty：`packItemSimFloats` → SSBO `[cellX,cellY,progress,dir,type,layer]*N`。
3. Compute 写出世界坐标（示例 `examples/factory`）；后续可直出 `GpuInstance` resident buffer。
4. 规模验证路径对齐 `docs/dev/2026-08-30-ecs-gpu-efficiency.md`：稳态少回读。

## 垂直切片验收

- 源 → 传送带 → 装配机 → 传送带 → 汇
- 至少完成一次合成且汇收到产物
- 可选：GPGPU 计算物品世界坐标并绘制
- `make test ... FILTER=logistics` 与 `scripts/smoke_examples.sh factory`

## 后续扩展（刻意不做在本切片）

- 分流/地下带/列车、电力网络、研究树
- 与 `building.PlacementWorld` 双向同步占用
- 多层楼梯与竖井、3D 网格
- Production `ReadyToSettle` 适配器替代内置计时
- GPU 上百万货物 resident 绘制不经 CPU 回读
