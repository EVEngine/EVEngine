# 空间索引模块设计 — `spatial`

日期：2026-08-09  
状态：Phase A 已实现（`src/modules/spatial/`）  
存放：`docs/dev/`

## 背景与结论

引擎此前**没有**通用的空间划分 / 快速裁剪查询结构：

| 易混淆能力 | 实际含义 | 是否覆盖本需求 |
|-----------|---------|----------------|
| `procgen` 的 `dungeon.bsp` | 地牢房间生成算法 | 否 |
| Box2D broad-phase | 物理内部，未导出通用 id 查询 | 否 |
| Tilemap「视锥裁剪 / chunk」 | 设计文档中的待办 | 否（可消费本模块） |

因此新增独立模块 **`spatial`**，专门提供地图 / 场景元素的 **AABB 宽相查询**（点、矩形/AABB、圆/球），供脚本与 C++ 系统做可见性裁剪、邻近查询、拾取候选等。

## 目标

1. 提供常见空间索引及其二维 / 三维版本：
   - **四叉树** `QuadTree`（2D）
   - **八叉树** `Octree`（3D）
   - **空间哈希** `SpatialHash2D` / `SpatialHash3D`
   - **空间二分树**（kd 风格 AABB BSP）`BSPTree2D` / `BSPTree3D`
2. 统一脚本模式：`insert` / `remove` / `update` → `query*` → `getResultCount` / `getResultId(i)`
3. 与 `math` / `map` / `scene` / `physics` 解耦：本模块只索引整数 `id` + 包围盒，不拥有实体

## 非目标（一期）

- 与 ECS / TileLayer 的自动挂钩（由玩法层把 entity id / object id 写入索引）
- GPU 加速结构、动态 BVH 重平衡最优解
- 精确三角形 / 多边形碰撞（窄相仍交给 physics 或自研几何）
- 无限流式大世界自动 chunk 流送

## 模块位置

```text
src/modules/spatial/
  Spatial.h/.cpp          Module facade + Squirrel expose
  Bounds.h                AABB2 / AABB3 工具
  QueryIds.h              查询结果缓冲
  QuadTree.*  Octree.*
  SpatialHash2D.*  SpatialHash3D.*
  BSPTree2D.*  BSPTree3D.*
```

CMake：`create_module(EVSpatial spatial)`，并加入 `EVELIBS` / `unit_test` 链接列表。

脚本入口：`spatial <- eve.Spatial()`。

## 核心抽象

```text
Spatial (Module)
  ├─ newQuadTree(minX,minY,maxX,maxY [,maxDepth,maxPerNode])
  ├─ newOctree(minX,minY,minZ,maxX,maxY,maxZ [,maxDepth,maxPerNode])
  ├─ newSpatialHash2D(cellSize) / newSpatialHash3D(cellSize)
  └─ newBSPTree2D(...) / newBSPTree3D(...)

每个索引对象：
  insert(id, bounds...)
  remove(id) / update(id, bounds...) / contains(id) / getCount() / clear()
  queryPoint / queryRect|queryAABB / queryCircle|querySphere  → 写入内部结果缓冲
  getResultCount() / getResultId(i)
```

绑定原则与全仓一致：**不使用重载**，2D/3D 与矩形/AABB、圆/球用明确方法名区分。

## 结构选择建议

| 结构 | 适合 | 注意 |
|------|------|------|
| SpatialHash* | 物体尺寸相近、频繁移动（粒子、角色、投射物） | `cellSize` 接近平均物体尺寸 |
| QuadTree / Octree | 地图静态/半静态物体、视口裁剪 | 需给定世界根包围盒 |
| BSPTree* | 细长分布或希望二分剪枝的场景 | 跨分割面物体停在父节点 |

## 与其它模块关系

- **消费**：无硬依赖；`id` 可由脚本自己映射到 entity / map object
- **服务**：`map` 视口裁剪、`scene` 节点邻近、自定义 gameplay 拾取
- **不替代**：`physics` 碰撞求解；`procgen` 地牢 BSP 生成
