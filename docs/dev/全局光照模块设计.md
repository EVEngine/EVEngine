# 全局光照（Global Illumination）设计

> 状态：前向半球/wrap、手动 SSGI、漫反射探针/体积插值已有实现。普通 `gi` 不自动叠加 fullscreen SSGI；显式 `rtgi` / `reflectionChain` 会在 RenderSystem3D 运行场景色/深度采样与反射光照组合（2026-11-11 源码核验）。
> API：`eve.Graphics().newGlobalIllumination()` → `GlobalIllumination`  
> 管线开关：`RenderControl` 特性 `"gi"`（默认开，隐含 `gbuffer` + `gbufferAlbedo`）

关联：[`模块设计.md`](./模块设计.md) §4 graphics、[`3D渲染管线.md`](./3D渲染管线.md)、[`环境光遮蔽模块设计.md`](./环境光遮蔽模块设计.md)、[`抗锯齿模块设计.md`](./抗锯齿模块设计.md)。

## 1. 目标观感

室内/箱体场景要有邻面染色（Cornell 红墙打到盒子）和阴影里的天空填充，而不是只有直射 + 常数环境光。

| 层 | 技术 | 何时 |
|----|------|------|
| 前向 mesh | 半球天空/地面 irradiance + wrap fill | 每像素，不依赖 GBuffer |
| 屏幕空间 | SSGI：邻像素 lit color × 接收端余弦 | 手动 `applyFromScene`，或显式启用 `rtgi` / `reflectionChain` |
| 漫反射探针 | 批量 SH 数据、局部体积八角插值/稀疏回退 | `DiffuseLightProbeRegistry` 与 Renderable 的提供系数路径 |

## 2. 架构

3D 画进可采样的 scene color（与 FXAA 共用）。GBuffer 仍在同一 command buffer 里先于 scene color 录制。3D SSGI 用两个 sampler：

```
MainTex  = scene color RGB（lit radiance）
DepthTex = GBuffer D32（.r = Vulkan NDC z）
```

Canvas / 单测仍可走打包路径：`applyFromDepth` 读 `MainTex.a` 作为线性深度。

`applyFromScene` 在 swapchain pass 里画全屏四边形（scene color 已 resolve 之后、HUD 之前），SrcAlpha 把场景混向反弹色。

## 3. API

```squirrel
gi <- gfx.newGlobalIllumination();
gi.setQuality("medium");
gi.setCamera(eye..., target..., up..., fov, aspect, near, far);
gi.setLightDirection(0.4, 1.0, 0.3);
gi.setLightColor(1.0, 0.95, 0.85);
gi.applyFromScene(gfx, gfx.getSceneColorTexture(), gb.getHwDepthTexture());
```

启用 `rtgi` 或 `reflectionChain` 时，`RenderSystem3D` 绑定世界法线、albedo、运动信息与深度金字塔，在 working canvas 调用 `applyFromSceneTo`，再参与反射光照组合。只启用基础 `gi` 不等于自动开启该 fullscreen 路径。
