# 生长模拟系统设计

日期：2026-11-04  
状态：已落地（宿主模块 `growth`）  
范围：农场游戏动植物生长（作物 + 畜牧 + 季节 + 疾病 + 繁殖），空间绑定为独立 ECS 实体（不绑 hex）。

## 目标

为农场玩法提供**确定性、可注入时间**的生长权威：

- 作物：阶段推进、需水/肥力、成熟、收获 Yield（不直接改 inventory）
- 畜牧：喂养、成熟、周期产出事件、繁殖妊娠与子代
- 季节：域内 `GrowthCalendar`（非 daynight 表现时钟）
- 疾病：应激时按命名哈希流感染，可痊愈并降低生长倍率

## 非目标（本切片）

- 不读写 hex `plantLevel` / `farmLevel`（地形装饰，见 `hexmap`）
- 不依赖 building 地块；田/畜栏由游戏脚本或后续可选适配器挂 Link
- 不实现完整库存结算；收获返回 `YieldReceipt`，由调用方写入 `inventory`/`transaction`
- 不把 daynight/weather 当作生长权威；它们至多作为环境输入适配器的数据源

## 短根与组件

```
Organism : ecs::Entity
├── Growth        speciesId / kind / stage / mature / dead / harvested
├── VitalNeeds    water / food / fertility（permille 0..1000）
├── Health        activeDiseaseId / daysLeft / growthMul
├── Reproduction  pregnant / gestationProgress
└── Produce       daysSinceProduce
```

Plant 与 Animal 不分子类：系统用 `View<Organism, …>` 统一推进；kind 与物种定义决定哪组需求生效。

## 推进入口

唯一权威：

- `GrowthWorld::advanceDays(double)`
- `GrowthWorld::step(SimulationStep)`（`delta.seconds / secondsPerSimDay`）

禁止用墙钟推进。日历只在整天边界前进；分数日按「到下一日边界」切片，避免重复结算。

## 模块边界（六面）

| 面 | 内容 |
| --- | --- |
| Capability | 本切片不发布 cap；后续环境适配器可 `query` 日历只读观察 |
| ECS | `Organism` 短根 + 上表组件 |
| Events | `GrowthEventLog`：stage_changed / matured / produced / harvested / watered / fed / fertilized / diseased / cured / bred / offspring / died |
| Script | `eve.Growth()` / `eve.Organism` |
| Tool | 无独立 MCP；可用脚本与单元测试驱动 |
| Definitions | 进程内 `SpeciesRegistry`（JSON 可加载）；未接入 `definitions` 包以免抬依赖 |

## 机制选型

- 每实体每 tick 批处理 → ECS View + `GrowthWorld`
- 收获 / 产出跨库存 → 回执 / 事件，不用 growth 直接改 inventory（原子性留给 `transaction`）
- 疾病随机 → `splitmix64(seed, stream, organismId^day)`，可复现

## 裁剪

`LAYER 0`，`GROUP minimal 2d 3d web`，无硬 DEPS。去掉本模块不影响渲染与其它玩法域。
