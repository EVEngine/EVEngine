# 生长模拟系统设计

日期：2026-11-04（可配置生命体系修订：2026-11-05）  
状态：已落地（宿主模块 `growth`）  
范围：数据驱动的生命体生长（作物 / 畜牧 / 外星生命 / 自定义生育），空间绑定为独立 ECS 实体（不绑 hex）。

## 目标

为玩法提供**确定性、可注入时间、物种 JSON 可配置**的生长权威：

- 任意 `kind` 字符串（不限 plant/animal）
- 命名需求计量（不限水/食/肥力）
- 阶段推进、成熟、收获 Yield、周期产出事件
- 繁殖模式：`pair_gestation` / `self_bud` / `fission` / `spore_burst` / `none`
- 可配置季节布局（不限地球四季）
- 疾病：应激时按命名哈希流感染

地球农场（小麦 / 牛）只是默认作者内容，不是引擎假设。

## 非目标（本切片）

- 不读写 hex `plantLevel` / `farmLevel`
- 不依赖 building 地块
- 不实现完整库存结算；收获返回 `YieldReceipt`
- 不把 daynight/weather 当作生长权威
- 不在 C++ 里为每种外星生物写分支；扩展只加物种定义

## 短根与组件

```
Organism : ecs::Entity
├── Growth        speciesId / kindId / kind / stage / mature / dead / harvested
├── VitalNeeds    meters[string → permille]
├── Health        activeDiseaseId / daysLeft / growthMul
├── Reproduction  pregnant / gestationProgress / daysSinceReproduce
└── Produce       daysSinceProduce
```

系统用 `View<Organism, …>` 统一推进；**行为由 SpeciesDef 驱动**，不按 `OrganismKind` 分支。

## 物种契约（摘要）

| 字段 | 作用 |
| --- | --- |
| `kind` | 自由标签；`plant`/`animal` 仅便利 API |
| `needs[]` | `{id, drainPerDay, minPermille, requiredForGrowth, lethalWhenEmpty}` |
| `stages[]` | 生长阶段 |
| `seasonMul` / `seasonMulById` | 日历倍率 |
| `produce*` / `harvestYield` | 产出与收获（任意 kind） |
| `reproduction` | `mode` + 模式参数（妊娠天数 / 间隔 / 子代数 / 亲本死亡或重置） |

旧字段 `waterDrainPerDay` / `canBreed` / `gestationDays` 在加载时归一化。

## 推进入口

唯一权威：

- `GrowthWorld::advanceDays(double)`
- `GrowthWorld::step(SimulationStep)`

禁止用墙钟推进。日历只在整天边界前进。

## 模块边界（六面）

| 面 | 内容 |
| --- | --- |
| Capability | 本切片不发布 cap |
| ECS | `Organism` 短根 + 上表组件 |
| Events | stage_changed / matured / produced / harvested / watered / fed / fertilized / diseased / cured / bred / offspring / died |
| Script | `eve.Growth()` / `eve.Organism`（`spawn` / `refillNeed` / `tryReproduce` / `setSeasonLayoutFromJson`） |
| Tool | 无独立 MCP |
| Definitions | 进程内 `SpeciesRegistry`（JSON） |

## 机制选型

- 每实体每 tick 批处理 → ECS View + `GrowthWorld`
- 收获 / 产出跨库存 → 回执 / 事件
- 疾病随机 → `splitmix64`，可复现
- 繁殖策略 → 物种数据上的 mode 枚举，避免为外星生物加 C++ 子类
