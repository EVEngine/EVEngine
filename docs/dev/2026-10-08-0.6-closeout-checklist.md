## 策略

0.6 **不新开大模块**。顺序固定为：

1. **真相对齐** — 文档/勾选与代码一致，避免发布说明撒谎  
2. **竖切硬化** — 三条示例可冒烟 + README 写清怎么跑/已知边界  
3. **小工具补洞** — 帧统计等低成本高收益项  
4. **绑定文档分批** — 只覆盖示例实际调用的 API  
5. **门禁** — architecture / quality / SDK consumer 绿后再打 Pre-release tag
