### 只读预编译第三方目录

已有完整第三方安装树时，可在配置阶段传入：

```sh
cmake -S . -B build -DEVENGINE_PREBUILT_THIRD_PARTY=/path/to/third-party-binary/win32-debug
```

该目录必须包含 `include/` 与 `lib/`。启用后 CMake 只从该目录读取头文件和库，并创建兼容现有模块依赖关系的空 `third-party` 目标；不会配置、构建或安装到这个目录。
