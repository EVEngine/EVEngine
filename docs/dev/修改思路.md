# 修改思路（历史备忘）

> **现行方向以模块清单 + Capability + 短根 ECS 为准。**  
> 下文保留 2026 年初的探索笔记，**不再作为实施路线**。

原先记录的探索项：

1. 使用 C++20 modules 加快整体构建 —— 未采用；当前靠模块裁剪与头文件扇出治理。
2. 使用 xmake 替代 cmake —— 未采用；根 `Makefile` + CMake 为唯一构建入口。
3. Type erasure 解耦 —— 部分由 `eve::cap::` / 开放 Link 承担。
4. Strategy 配置分配器 —— 未作为全局方向。
5. concept 约束 template —— 局部使用，非架构主轴。
6. ECS 批量处理 —— **已采纳**，见 `领域短根继承与跨域组合架构.md`。
