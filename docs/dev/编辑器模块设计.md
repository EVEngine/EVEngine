# 编辑器模块设计 — `editor`

日期：2026-08-11  
状态：Phase A 已实现（`src/modules/editor/`）  
存放：`docs/dev/`

## 背景与结论

EVEngine **不内置**完整的 3D 场景编辑器或 2D 地图编辑器（与 Love2D / 运行时即编辑理念一致）。  
游戏与工具作者需要自行组装编辑器；引擎应提供**可组合的编辑器构件**，而不是一个封闭的 Editor App。

| 能力 | 本模块提供 | 不提供 |
|------|-----------|--------|
| 3D 变换操纵 | 操作框（gizmo）几何、拾取、拖拽解算 | 完整场景视口 / Outliner |
| 地图绘制 | 笔刷工具 + 独立瓦片缓冲 | 替代 Tiled 的完整 GUI |
| 编辑器 UI | Toolbar / Inspector / Dock / History 状态机 | 替代 `ui` 的渲染后端 |

## 业界 API 参考（调研摘要）

### 3D Gizmo

| 引擎 / 库 | 模式 | 要点 |
|-----------|------|------|
| **Three.js `TransformControls`** | 单实例单 mode：`translate` / `rotate` / `scale`；`attach` / `detach`；`space` local/world；snap | 模式切换清晰；一次只拖一种变换 |
| **Babylon.js `GizmoManager`** | 可同时启用 position / rotation / scale / boundingBox；指针自动 attach；UtilityLayer 绘制 | 管理器编排多 gizmo；事件 `onDrag*` |
| **ImGuizmo** | 即时模式 `Manipulate(view, proj, op, mode, matrix)`；TRS 分解/重组；snap | 与 ImGui 同帧；矩阵进出 |
| **Godot `EditorNode3DGizmoPlugin`** | 插件注册；`_redraw` / `_set_handle`；材质变体 | 可扩展自定义手柄，非通用 TRS |

**本模块取舍：** 以 Three 的单 mode `TransformGizmo` 为操作核心；以 Babylon 风格 `GizmoManager` 编排多 mode 启用与统一 attach；交互为 **射线拾取 + 拖拽解算**（不绑死 ImGui / Vulkan），绘制数据以 `getPart*` 导出给宿主渲染（`graphics` 调试线 / `ui` overlay 均可）。

### 地图笔刷

| 参考 | 要点 |
|------|------|
| **Unity `GridBrushBase`** | `Paint` / `Erase` / `FloodFill` / `BoxFill`；可脚本化；Inspector 与 SceneGUI 分离 |
| **Tiled** | 笔刷 / 橡皮 / 填充 / 形状；stamp 图章；与图层解耦 |

**本模块取舍：** `Brush` 对独立 `TileBuffer` 操作（不硬依赖 `map.TileLayer`），工具名用 string：`paint` / `erase` / `fill` / `line` / `rect` / `stamp`。脚本再把缓冲同步到 `map`。变更列表可供 `EditorHistory` 做撤销。

### 编辑器 UI 辅助

| 参考 | 要点 |
|------|------|
| ImGuizmo 示例 | Radio 切换 mode + TRS float 输入 + snap |
| Godot Dock / Inspector | 分区布局 + 属性行 |
| Unity Palette | 工具条 + 笔刷选项面板 |

**本模块取舍：** 提供 **状态与描述符**（Toolbar / Inspector / Dock / History），由现有 `ui` 模块渲染；不直接调用 ImGui。

## 目标

1. `TransformGizmo`：平移 / 旋转 / 缩放 / 包围盒手柄；local/world；snap；射线拖拽；绘制部件查询  
2. `GizmoManager`：多 mode 开关、attach/detach、转发 pick/drag  
3. `TileBuffer` + `Brush`：地图编辑笔刷与预览 / 变更表  
4. `EditorToolbar` / `EditorInspector` / `EditorDock` / `EditorHistory`：快速搭编辑器壳  
5. 脚本：`editor <- eve.Editor()`；无重载，枚举用 string  

## 非目标（一期）

- 内置完整 3D/2D 编辑器可执行程序  
- 自动挂接 ECS / SceneNode / TileLayer（由脚本粘合）  
- GPU 拾取缓冲、多选变换、骨骼手柄  
- 替代 `ui` 的控件渲染

## 核心 API 草图

```text
Editor
  newGizmo() / newGizmoManager()
  newTileBuffer(w,h) / newBrush()
  newToolbar() / newInspector() / newDock() / newHistory()

TransformGizmo
  setMode("translate"|"rotate"|"scale"|"bound")
  setSpace("local"|"world")
  setPosition / setRotationEuler / setScale / setBounds
  setSnapTranslate / setSnapRotate / setSnapScale
  pick(ox,oy,oz, dx,dy,dz) → axis string
  beginDrag / updateDrag / endDrag
  getPartCount / getPartKind / getPartAxis / getPart* …

Brush + TileBuffer
  setTool / setSize / setShape / setTile / stamp*
  paintAt / eraseAt / floodFill / paintLine / paintRect
  preview* / getChange*

EditorHistory
  beginGroup / recordTile / endGroup / push / undo / redo
```

## 与其它模块关系

- **消费**：无硬依赖；可选配合 `math` 射线、`graphics`/`scene` 画 gizmo、`map` 同步瓦片、`ui` 画壳  
- **不替代**：DevTools、Tiled、完整场景编辑器
