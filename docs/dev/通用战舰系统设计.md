# 通用战舰系统设计 — `warship`

日期：2026-11-06
状态：Phase 1 已实现（分支 `cursor/warship-module-5c92`）
存放：`docs/dev/`

## 目标

为 EVEngine 提供一套**类比载具、但尺度与内部结构不同的大型舰艇框架**，覆盖：

1. **多种舰种**：战舰 / 帆船 / 航母 / 星际战舰——区别落在 `category` + `mobility`，而不是平行模块。
2. **巨大空间尺度**：船体 `length` / `beam` / 多层 `decks` 远大于典型 `vehicle`。
3. **可重组舱段**：船体内部是格子网格；每个格子可放置不同**功能舱**（舰桥、反应堆、引擎、机库、武器舱、生活区、帆具、护盾等），布局变更投影为能力（推力、电力、机库容量、武器位、船员配额、帆力）。

## 非目标（Phase 1）

- 不做完整室内几何 / ArchSpace 文档同步（后续可选投影）。
- 不做武器挂点与物理刚体（继续组合既有 `weapon` / `vehicle` / `fluids`）。
- 不做寻路、网络同步、存档格式（事件 + 组件状态可后续序列化）。
- 不把战舰做成 universal GameObject；舱段功能也不是第二套载具座位系统。

## 与 `vehicle` 的关系

| 面 | `vehicle` | `warship` |
|---|---|---|
| 实体短根 | `VehicleEntity` | `WarshipEntity` |
| 差异核心 | 机动 / 座位 / 轮胎 / 挂点 | **可重组舱段网格 → 能力投影** |
| 已有 `"ship"` mobility | 水面语义占位 | 本模块内建 `surface` / `sail` / `carrier` / `space` |
| 组合 | 小中型载具与炮塔 | 大型舰体；挂点/海洋渲染留给后续 Link |

不要在 `vehicle` 里硬塞多层舱段；也不要 fork 轮胎/座位栈到战舰模块。

## 模块声明

```cmake
eve_declare_module(NAME warship LAYER 5 SCRIPT Warship SLOT warship
                   GROUP 2d 3d web)
```

脚本入口：`eve.Warship()` / `eve.view(eve.WarshipEntity)`。

## 实体与组件

| 组件 | 内容 |
|---|---|
| `Identity` | 实例 id / 模板 id / 阵营 / category |
| `Definition` | 借用注册表中的 `WarshipDefinition*` |
| `Input` | throttle / steer |
| `Motion` | x/y/heading/speed + move 目标 |
| `Health` | hp / maxHp |
| `Hull` | length / beam / decks |
| `Layout` | `CompartmentGrid` + 每格 `functionId` |
| `Capabilities` | 由 Layout 投影的电力/推力/机库/武器/船员/帆力 |
| `Flags` | destroyed |

## 舱段功能目录

`registerFunctionsFromJson` 注册功能；字段：

- `powerDraw` / `powerProvide`
- `thrustBonus`
- `hangarCapacity` / `weaponBayCount` / `crewCapacity`
- `sailPower`

`placeCompartment` / `clearCompartment` / `swapCompartments` / `rearrangeFromJson` 修改 Layout。
`rearrangeFromJson` **失败原子**：校验失败时不改写现有格子。

电力净值 `< 0` 时标记 `underpowered`，机动推力按系数衰减，并推送 `underpowered` 事件。

## 机动模型

| 注册名 | 用途 |
|---|---|
| `surface` | 水面战舰默认 |
| `sail` | 帆船；受 `sailPower` 加成 |
| `carrier` | 航母：更慢、转向更钝 |
| `space` | 星际：更高加减速 |

可通过 `Warship::registerMobility` 扩展。
