# Agent 实现与验收

新增通用 `agent` L0 模块，manifest 统一声明，默认按奖励学习，不限定测试用途。C++ 与 Squirrel 共用 run/infer/replay 和 Codec；接入协议为 reset/step。`agent/tensor` 为 L6 可裁剪 provider，提供生产 Tensor eager CPU 和 GPU 编译图，不使 agent 反向依赖 tensor。

适用架构要求：

- 可能失败的操作均返回 checked Result；状态观察与操作失败分离。
- 环境拥有领域状态；报告、轨迹和权重按值拥有。同步借用不跨调用保留，无 Link 或 ECS System。
- 时间、环境 RNG、搜索 RNG 和学习 RNG 显式注入；回放不用训练模型重选动作。
- 配置、模型与回放输入先验证。环境执行失败会传播，环境本身可能停留在最后已执行状态；隔离环境是调用契约。
- Policy/Trace 的 Value/JSON codec 使用 schema/version、未知字段拒绝、原子 owning 解码；完整 uint64 seed 以字符串编码。版本 1 尚无旧发布版本需要迁移。
- tensor provider 的注册拥有者在析构前 revoke；核心每次推理/训练重新 query，不把裸 provider 留过环境回调。tensor-cpu/cpu-sgd 与 tensor-gpu/tensor-gpu-sgd 分开报告，缺少 provider 或设备返回 Unsupported。GPU 图只有缓存算子和缓冲区，Policy 权重仍为唯一权威，返回值全量验证后发布；设备生命周期必须覆盖缓存图。
- Squirrel 使用公共 Result/Value 投影；callback 抛错传播为 CallbackFailure，run/replay 重入返回 Conflict，VM 栈和 active 状态由作用域守卫恢复。结果表独立拥有数据。没有采用架构例外。
