# 体积光 / 体积雾设计

> 状态：screenspace God Rays、depth Ray March 光柱、高度/距离体积雾、froxel 大气、
> 以及 **Light2D/Light3D 体积标志接线 + 发光体代理** 均已落地。  
> API：`eve.Graphics().newVolumetric()` → `Volumetric`

## 发光体与灯光接线（2026-09）

此前 `Light2D`/`Light3D` 的 `setVolumetric` 仅存标志，不进入任何体积通道。现已接通：

| API | 作用 |
|-----|------|
| `Light2D/3D.setVolumetric(true)` | 参与体积收集 |
| `setVolumetricOnly(true)` / `createEmissiveProxy(...)` | 只进体积、跳过表面光照（霓虹/熔岩等发光体代理） |
| `vol.driveFromLight3D` / `driveFromPrimarySceneLight3D` | 自动写入 shaft 方向、UV、颜色、强度 |
| `vol.collectSceneLights3D` / `integrateFroxelFromSceneLights` | froxel 局部光注入 |
| `vol.beginOcclusionMapFromSceneLights2D` / `scatterFromSceneLights2D` | 2D 多光源神光 |
| `vol.injectEmissiveLightProxy` | 一次性 froxel 发光注入（无需 ECS 实体） |
| `vol.setAnisotropy` | raymarch 双叶 HG 各向异性 |

推荐搭配：PBR `emissive` + bloom 负责表面自发光观感；同位置放 `createEmissiveProxy` / `volumetricOnly` 点光负责尘雾散射。

Shader 质量改进：screenspace 软膝 + 抖动去条带；raymarch 双叶 HG、软屏空间阴影、空间 dither、高度调制密度；fog 双叶相函数。

除屏幕空间光束、参与介质和高度雾外，`Volumetric` 还提供 `cloud` 模式：在世界
空间上下高度之间求交一个云层包围体，以程序化三维 fBm、天气尺度覆盖率和高度
剖面构造密度，通过视线 ray march、太阳方向次级步进、双叶 HG 相函数和 powder
近似生成可从云下或云上观察的体积云。

```squirrel
local cloud = gfx.newVolumetric();
cloud.setMode("cloud");
cloud.setCloudLayer(8.0, 16.0);
cloud.setCloudCoverage(0.62);
cloud.setCloudDensity(1.1);
cloud.setCloudScale(20.0);
cloud.setCloudWind(1.5, 0.4);
cloud.setCamera(/* 与主相机相同参数 */);
cloud.setLightDirection(sunX, sunY, sunZ);
cloud.setTime(seconds);
cloud.renderCloudsTo(gfx, linearDepth, cloudCanvas);
```

质量档分别使用 16/32/64 个视线采样和 3/6/10 个太阳阴影采样。建议在
`resolutionFor()` 返回的低分辨率 Canvas 中渲染，再使用引擎的抗锯齿/上采样
路径合成。当前实现是第一阶段程序化 MVP；后续 weather map 与预生成 3D 噪声
可替换 shader 内噪声而保持脚本 API 不变。

关联：[`模块设计.md`](./dev/模块设计.md) §4 graphics、现有 `Drawable` / `Shadow` / `Canvas` / `Shader`。

## 1. 目标观感

有尘、有雾的参与介质渲染：

| 模式 | 技术 | 适用 |
|------|------|------|
| `screenspace` | GPU Gems 3 径向模糊 + 尘/雾 tint | 2D / 屏内亮源 |
| `raymarch` | 沿视线积分光柱 + 屏空间遮挡近似 CSM | 3D 线性深度 |
| `fog` | 高度指数 + 距离 ramp 的 Beer-Lambert 体积雾 | 3D 线性深度 |

完整 froxel 3D 纹理网格仍可选后续。

## 4. API

```squirrel
vol <- gfx.newVolumetric();
vol.setQuality("medium");

// --- 体积雾 ---
vol.setMode("fog");
vol.setCamera(eye..., target..., up..., fov, aspect, near, far);
vol.setLightDirection(0.3, 1.0, 0.2);
vol.setFogColor(0.55, 0.62, 0.75);
vol.setFogHeight(0.0);
vol.setFogHeightFalloff(0.15);
vol.setFogStart(2.0);
vol.setFogEnd(40.0);
vol.setFogNoise(0.35);
vol.setDensity(0.25);
vol.applyFog(gfx, linearDepthTex); // 输出非预乘雾色 + alpha，SrcAlpha 叠加到场景
```

> 引擎 2D textured pipeline 使用 `SrcAlpha / OneMinusSrcAlpha`。若目标画布已是不透明黑 `(0,0,0,1)`，混合后 alpha 恒为 1；测量雾浓度请清成透明，或读 RGB。

质量档（fog）：

| quality | samples | noise | 默认 density |
|---------|---------|-------|--------------|
| low | 8 | 0.15 | 0.18 |
| medium | 24 | 0.35 | 0.25 |
| high | 48 | 0.45 | 0.32 |
