## Reproduce a capture

```powershell
./scripts/capture_example.ps1 -Eve <compatible-full-build/eve.exe> -Example layered-animation -Out build/layered-animation.png -Frames 120
```

The capture script composes a post-frame hook into the repository standard load.nut. It requires a fresh PNG and a CAPTURED marker and rejects initialization/frame errors. Failed runs preserve earlier gallery images. Weather uses 150 frames; Fluid3D uses 180; other new captures use 120. Presets and runtime/source hashes are recorded in the manifest.
