# Choose an Example

[User guide](README.md) · [English example index](../../../examples/README.en.md) · [Render gallery](../../images/examples/README.en.md)

The SDK includes `share/eve/examples/basic`. Run it first, then copy it into your own game directory before editing. The other examples are supplied with the repository; download the source for the same release tag as your SDK. Development-branch examples may need a corresponding source build.

For a first session, use [Basic](../../../examples/basic/README.en.md). To learn debugging and hot reload, use [DevLab](../../../examples/devlab/README.en.md). For a visual introduction, try the [terrain editor](../../../examples/terrain-editor/README.en.md), [RPG](../../../examples/rpg/README.en.md) or [roguelike generator](../../../examples/roguelike-generator/README.md).

For AI integration, read [AI and MCP](AI-MCP.md), then the [AI Game](../../../examples/ai-game/README.en.md) and [AI Editor](../../../examples/ai-editor/README.en.md) walkthroughs. The example index explains commands, source-build alternatives and version matching.

These English pages are maintained manually from the Chinese guides. Screenshots illustrate existing captures; they are not a compatibility test for your downloaded SDK.
