详细描述

Configure-then-run builder for bounded black-box numerical balancing. @ownership Owns configuration; borrows evaluators synchronously and returns owning reports. @thread Owner thread only. configure/run reentry returns Conflict. No background work or retained callbacks.

备注
The initial configuration is always candidate zero; selection sees training seeds only. Search evaluates lower and upper parameter corners when budget permits, then uses local feasible coordinate restoration, SplitMix64, global exploration and shrinking mutations of the best proposal. Same build and deterministic evaluator reproduce results; cross-platform floating point uses tolerance. No ECS state, links, persistence, rendering or optional backend is introduced.
