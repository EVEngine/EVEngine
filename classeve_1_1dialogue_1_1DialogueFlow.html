◆ configureIntegration()

void eve::dialogue::DialogueFlow::configureIntegration ( IntegrationConfig  config)

Configure every runner in this module facade in one operation.

Call while the flow is inactive, before start, and on the same thread that will call start, advance, select, or applyStateMutations. The provider pointers are borrowed and must outlive this facade, or the caller must call clearIntegration() first. Handlers receive an owning request snapshot and must not retain it or re-enter this facade. DialogueFlow owns no world state and creates no second state mirror.
