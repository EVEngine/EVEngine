详细描述

Toolset / read-only / exclude filtering for the embedded MCP server.

Agents drown when tools/list returns 130+ schemas. Env-driven filters shrink the advertised surface and reject calls that are outside the active set, so list and call stay consistent (Godot MCP toolset/read-only pattern).

Environment:

  • EVE_MCP_TOOLSET — comma-separated tags (all default): core, debug, play, editor, host, scene, input, domain, agent
  • EVE_MCP_READONLY=1 — hide / reject mutating tools
  • EVE_MCP_EXCLUDE — comma-separated exact tool names to drop
  • EVE_MCP_PROFILE — named task profile (verify.play, content.scene, …); stacks with toolset tags and with the session profile from eve_agent_session_start (see McpTaskProfile.hpp)
