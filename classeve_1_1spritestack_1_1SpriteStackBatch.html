详细描述

Multi-stack batching: draws every visible slice of the registered stacks as ONE draw call per (texture, tint) group (all slice transforms and UV rects are baked into a shared mesh, uploaded in place via Graphics::updateMeshVertices).

The combined mesh is rebuilt only when a registered stack changes (revision counter); per-frame animated stacks should keep using SpriteStack3D::render. Shadows / outlines are per-stack features and are not included in batches.
