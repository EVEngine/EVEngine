详细描述

Own one realized terrain Detail set and submit it from RenderSystem3D's forward phase.

The resolver is borrowed and must outlive this object. Construction and destruction are graphics-thread operations. The realization is owned so import/hot-reload code can atomically replace the renderer without retaining temporary loader storage.
