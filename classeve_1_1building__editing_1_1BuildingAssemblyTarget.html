详细描述

Whole-house transaction target sharing the canonical runtime world state. @ownership Borrows a world; the host must destroy this target before the world. @thread Owner/editor thread only; staging does not publish observer callbacks. @lifetime Prepared operations own snapshots; they never retain the target/world.
