详细描述

Pure force evaluators for 2D XY slices and full 3D, returning owning SI values. @ownership Inputs are borrowed only for this call; no state or callbacks are retained. @thread Any thread with immutable inputs; reentrant and allocation-free on success.

返回
InvalidArgument for non-finite/invalid input or non-finite output; no partial mutation.

Time is injected in seconds. No RNG. Floating-point parity is tolerance-bounded (relative 1e-5, absolute 1e-6), not bit-exact across platforms. Apply each sample once before its fixed solver step. Damping is implicit over dt to avoid velocity reversal. Tire contact uses implicit slip impulses with frozen per-step stiffness and a bounded brake solve.

Implicit angular drag in the body's principal-inertia frame; returns torque in that same frame.

All principal inertias must be positive kg*m^2. Rotate relative angular velocity into that frame, then rotate returned Nm torque to world before applying. Does not include gyroscopic or external torques.

static

Combined-slip friction-circle tire with implicit wheel/chassis response and bounded brake locking.

Input inverse masses describe diagonal contact response; zero keeps the corresponding chassis velocity prescribed. Returned forces and wheel speed share the same impulses. Slip diagnostics describe predicted end-of-step relative motion. Uses a fixed bounded brake solve; InvalidArgument also reports unrepresentable/nonconvergent numeric input.
