详细描述

Composable runtime pose graph supporting clips, blends, additive layers, per-bone masks, one-shots and 1D/2D blend spaces. Script type: AnimGraph.

Nodes are stable integer handles. A graph owns runtime state but not skeletons or clips; those must outlive the graph. Call advance(step) once per frame and read getPose(). Graph evaluation is memoized so shared subgraphs sample only once.
