详细描述

Interactive timeline adapter shared by developer and in-game editor hosts.

The widget borrows an editor and notify registry that must outlive it. Pointer drags mutate only widget preview state until pointerUp commits exactly one undoable domain transaction. All methods are owner-thread-only.
