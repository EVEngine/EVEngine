详细描述

CPU-authoritative deterministic 3D mesh-particle emitter.

The emitter owns particle state and retains no graphics resources. Given the same config, seed, origin, command sequence and delta sequence, snapshots are bitwise stable on the same floating-point implementation. Structural changes are deferred until each simulation step has finished iterating live particles.
