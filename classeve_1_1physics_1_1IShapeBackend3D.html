详细描述

Sole owner of native shape and cooked resources; facade owns portable source geometry. @thread Owning simulation thread, between steps; no user callbacks or concurrent mutation. @lifetime Owning results survive mutation. Input views are borrowed only for this synchronous call.

备注
Result failures leave native state unchanged. Native IDs and cooked data never escape.
