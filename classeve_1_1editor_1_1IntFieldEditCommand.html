Creates an owning staged copy for merge evaluation.

返回
A detached command copy, or null when this command has no candidate-merge representation.
备注
The copy may retain the same borrowed target because the consumer evaluates mergeWith() before publishing the incoming command to that target. It must not mutate the target itself.
