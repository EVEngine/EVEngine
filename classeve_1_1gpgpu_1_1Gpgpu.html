详细描述

GPGPU module — compute shaders + storage buffers via the active Graphics backend. Uses the graphics queue when no dedicated compute family exists (Apple/MoltenVK).

Script: gpgpu <- eve.Gpgpu(); shader <- gpgpu.newShader(glsl); ECS: eve.ShaderSystem / eve.EcsShaderSystem bridge entity float fields to SSBOs.
