详细描述

Deterministic 2D factory logistics: belts, discrete items, machine buffers, crafts.

Grid cells are the authority for belt topology. Items are a dense SoA (not one ECS entity per cargo). Machines own input/output buffers and an optional in-module craft timer; they expose machineOwnerId so a game can project the same work onto production WorkQueues.

Layer 0 is the only active floor in the vertical slice; configure accepts layers so a later multi-floor / 3D host can reuse the same cell addressing (x,y,layer).

@thread Simulation owner thread only. @reentrancy No callbacks; no graphics includes.
