详细描述

An editable, chunked, pointy-top hex map.

The grid is rectangular in odd-row offset space: cellCountX columns and cellCountZ rows, with odd rows shifted half a cell to the right. Cells are partitioned into chunkSizeX * chunkSizeZ chunks; every mutation marks the owning chunk (and the chunks of affected neighbours) dirty so a renderer can rebuild only what changed.

Ownership and lifetime: HexMap owns its cell storage and its noise field and is a plain value type. It performs no I/O, opens no GPU resources and invokes no callbacks, so it is safe to hold on any single thread.

Determinism: cell positions, perturbation and any future generation step are derived from the construction seed and the cell coordinates only. Two maps built with the same size and seed produce identical positions.

◆ contains()

bool eve::hexmap::HexMap::contains ( HexCoordinates  coordinates) const
inlinenoexcept

Whether coordinates address a cell inside the grid.

The grid is the rectangle [0, cellCountX) x [0, cellCountZ) in odd-row offset space. An axial pair is inside only when its offset column x + z/2 is in range, so cells with a negative axial X are valid members of the rectangle.
