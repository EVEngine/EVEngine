enum class eve::condition::ConditionReasonCode : std::uint32_t
strong

Stable machine-readable explanation code for a condition outcome.

Active evaluation paths emit Passed, ChildFailed, NoChildPassed, Negated, MissingValue, ValueMismatch, PolicyRejected, PolicyUnavailable, AuthorityDenied, AuthorityUnavailable, and InvalidCondition. The remaining codes are retained for snapshot compatibility with older fact stores.

枚举值
