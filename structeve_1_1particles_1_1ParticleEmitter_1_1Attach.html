详细描述

Optional bone attachment. When enabled, syncAttach() writes Config.x/y (and optionally direction) from a live skeleton each frame. Particles remain 2D; 3D bone XYZ is projected via plane + scale.

Supported sources (mutually exclusive):

  • AnimPose + bone index (3D skeletal animation)
  • SpineSkeleton + bone index (2D Spine)
  • IK Skeleton2D / Skeleton3D + bone id (FABRIK chains)
