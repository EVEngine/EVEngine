详细描述

Typed SkillDefinition-to-runtime adapter.

The registry is borrowed and must outlive this object. All methods are synchronous and owner-thread affine. RebuildInstance is the default policy: it adopts the new typed definition while retaining a valid cooldown/learned state. RejectWhileActive uses the adapter active flag; callers set it while a cast session owns the skill.
