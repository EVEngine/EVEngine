详细描述

Prepared sprite-batch consumer of recorded particles, independent of source emitters. @ownership Owns immutable asset and CPU buffers only; caller owns playback state; never retains graphics or material resource references between calls. @thread Render-owner thread with exclusive access; no scripts or simulation calls.

Sample and submit sprites through the ordinary 2D batch renderer. @ownership Borrows Graphics and material only during the call; caller supplies live resource references. @lifetime Textures, shaders, camera and canvas in material must remain valid through Graphics frame completion.

备注
Material supplies resource/layer/blend/light policy. Recorded geometry, color, UV and identity order replace those fields. Anchor is center, flip flags are disabled. No implicit time advance or source simulation access. @cost Linear in visible births plus existing renderer sorting/upload, per presented frame; CPU buffers reused.
返回
Submitted count or sampling failure before submission. The renderer owns backend diagnostics; successful submission does not by itself establish GPU completion. Canvas selection is restored to screen.

Draw using strictly identity-sorted, unique per-emitter material templates. @ownership Borrows bindings and templates only during this call; no resource references retained afterward. @lifetime Every supplied graphics resource must remain live through Graphics frame completion. @cost Linear binding validation plus logarithmic lookup per visible birth and renderer sorting/upload.

返回
Submitted count or invalid/missing binding/sample failure before any draw submission.
备注
Up to 65536 bindings. Every visible emitter must be bound; extra bindings are allowed for dead emitters.
