详细描述

One argument passed to a script provider method.

The bridge marshals values: the four scalar kinds plus an owning object (Table) for capabilities whose payload is a record rather than a number. A module that serves a capability from script decides which of its fields cross the boundary, in what order.

备注
用户 2026-09-20 的决定③（"全面加对象/表参数 + 结构化返回"）把这条边界从"只有标量" 放宽到"标量 + 对象"。代价是这里多一层编组语义，所以 call/callNumber 的 @cost 要 按"构造一个表"而不是"几个标量压栈"来读（见下）；Table 载荷仍走 common/SquirrelBinding.h 那一套权威转换（递归/元素数上限、环检测、非有限数拒绝）， 桥本身不新增第二套递归转换。
