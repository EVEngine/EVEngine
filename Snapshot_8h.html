详细描述

Versioned, integrity-checked persistence envelopes.

SnapshotEnvelope owns the stable header and delegates domain state to an owning eve::Value payload. It deliberately has no wall-clock field: deterministic hash input is assembled only from the stable header and payload. The hash algorithm is injected by the caller because ContentId must not silently imply a cryptographic or weak substitute algorithm.
