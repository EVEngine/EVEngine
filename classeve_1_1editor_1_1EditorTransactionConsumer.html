详细描述

Editor consumer of the common transaction participant/coordinator protocol.

This class owns the editor transaction history. It adapts legacy reversible IEditCommand objects to the generic prepare/commit/rollback/compensate lifecycle, and adapts IEditAuthority for serializable DomainOperation work. The consumer is synchronous and owner-thread-only. Authorities, command targets, and extra participants are borrowed and must outlive the call that uses them. No callback is invoked while an internal lock is held.
