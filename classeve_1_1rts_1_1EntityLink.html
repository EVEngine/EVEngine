详细描述

template<typename Tag>
class eve::rts::EntityLink< Tag >

Generation-checked link to an ECS entity.

The link owns no target. bind() validates the handle immediately; resolve() performs the generation check again, so target destruction or slot reuse becomes observable as a stale link. fromHandleForRestore() is reserved for restore/import code that will validate before use.
