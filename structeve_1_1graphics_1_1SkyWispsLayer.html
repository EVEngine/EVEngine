详细描述

Borrowed authored thin-cloud layer, consumed synchronously by sky preparation.

Triangle-list corners are x,y,z,u,v,r,g,b,a in Unreal local centimetres. Coordinates convert to native (x,z,y) metres, with the explicit uniform dome scale. Texture storage/sRGB interpretation is explicit in densityTexture; its binding is reassigned. No file loading, provider pointers, clocks or callbacks are retained. All values are copied to GPU storage. This is a runtime upload description, not a persistent file schema.
