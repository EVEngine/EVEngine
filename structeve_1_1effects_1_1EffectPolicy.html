详细描述

Independent policy dimensions used when applying an effect definition.

StackMode selects the instance relationship. The remaining dimensions are evaluated independently when an existing instance is reused or accumulated. maxStacks == 0 means unlimited; otherwise it is the maximum stack count for one instance.
