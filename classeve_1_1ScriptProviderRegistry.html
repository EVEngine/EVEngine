详细描述

Named script objects that native systems drive through named methods.

A native system needs to call into user script without knowing the script class. This registry is that seam: a script object is published under a stable name, the registry roots it for as long as it is published, and callers invoke a method by name. A method the object does not implement is Unsupported, not a crash and not a silent no-op.

Deliberately minimal: it resolves nothing by itself. A caller that wants to serve a cap:: capability from script publishes the instance here and adapts it; the registry only owns the identity, the rooting and the call.

@ownership The registry owns one VM reference per published provider. Callers hold borrowed handles, never the object. @lifetime A published provider stays valid until unload or clearAll. Handles outlive retirement on purpose and then report StaleHandle. @thread Main/script thread only, like every other Squirrel entry point. There is no internal lock: a lookup and a call both touch the VM. @reentrancy A published method is user script and may re-enter the registry (publish, unload) while it runs. call therefore re-resolves after the call only for its own bookkeeping and never holds a reference to the provider across an invocation it does not own.

Result< Value > eve::ScriptProviderRegistry::callValue ( const ScriptProviderHandle &  handle,

Call method(...) and read the script result as an owning eve::Value.

决定③（2026-09-20）的"结构化返回"这一半：插座可以拿到一个**对象/数组**而不是一个数。 典型用途是 ISensingCandidateProvider / IStateQuery 这类"问一次、答一组"的接口。

参数
handlePublished provider handle.
methodMethod name on the provider object.
argsPositional arguments in call order; may be empty.
返回
The result as an owning Value tree: Null/Bool/Int64/Double/String/ Array/Object，或与 call 相同的失败（Unsupported/StaleHandle/Failed）， 外加转换失败时的 InvalidArgument。 @cost One script call plus one whole-tree projection. The result is copied, not viewed: per-frame callers should keep asking for scalars (callNumber) and only reach for a structured return when the payload genuinely is a record.
备注
载荷边界由 common/SquirrelBinding.h 的权威转换负责（默认深度 64、元素 100000， 拒绝环与非有限数）。需要更紧的上限就用 callNumbers（64 个元素）那条路。 @lifetime 返回值拥有自己的存储，脚本 VM 销毁后依然可用。

◆ declareCapability()

void eve::ScriptProviderRegistry::declareCapability ( std::string  capability,
ScriptCapabilityBinder  binder,
ScriptCapabilityUnbinder  unbinder 
)

Declare that one native capability may be served by a script provider.

Called once per capability by the module that owns the interface, at composition time. The module supplies the marshalling because it is the only party that knows its own interface; the registry just routes the binding, so no central table has to enumerate every capability.

参数
capabilityNative capabilityName string, e.g. "IVehicleDamageModifier".
binderInstalls the native adapter for one published provider. Called synchronously during publishForCapability.
unbinderRemoves the adapter again. Called by unload, clearAll and a failed publishForCapability. @cost One map insert. Declare at composition time, never per frame.
备注
Redeclaring the same capability replaces the previous pair. Both callbacks must be callable: a capability with no unbinder would leak its adapter across a hot reload.

Result< ScriptProviderHandle > eve::ScriptProviderRegistry::publish ( std::string  name,
const ssq::Object &  instance

Publish one live script instance under a stable name.

参数
nameNon-empty stable provider name; republishing supersedes it.
instanceLive script instance; the registry takes its own VM reference.
返回
The new generation-qualified handle, or a structured failure. @cost One VM reference plus a map insert. Call at load/publish time, never per frame.
备注
Republishing the same name retires the previous generation without destroying it: outstanding handles report StaleHandle afterwards. When the superseded generation was capability-bound, its unbinder runs first and a failure there fails this call – the superseded generation stays retired either way, so the name has no live provider afterwards.

返回
Success, or NotFound when capability was never declared. @cost One map erase.
备注
Only the ability to bind again is withdrawn. A provider that is already published keeps its generation and its installed adapter, so unloading it still runs the unbinder it was published with.
