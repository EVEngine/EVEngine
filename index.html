EVEngine 文档
简介
EVEngine（Evolutionary Vision Engine）是一款以 Squirrel 脚本驱动的轻量游戏引擎， 适合快速制作 2D、第三人称 3D 与 2D/3D 混合的游戏原型。引擎内置热重载、调试器、 声明式 UI、ECS、物理、程序化生成、RPG 等 40+ 模块，支持 Windows / Linux / macOS / Android / iOS 打包发布。

本站在线提供用户手册与 C++ API 参考，随 GitHub Pages 持续发布。

快速开始（游戏开发者）
使用 EVEngine 做游戏不需要编译引擎：到官网发布页 （GitHub Releases） 下载对应平台的预编译 SDK，解压后执行 eve run <游戏目录> 即可开始创作。 完整流程见 EVEngine 用户指南。
