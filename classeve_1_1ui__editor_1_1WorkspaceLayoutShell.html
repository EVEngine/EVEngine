详细描述

Builds a fixed, non-draggable editor chrome from an EditorWorkspace.

Domain editors stay UI-neutral: they only register WorkspacePanelDescriptor entries. This shell maps those descriptors into one Window with AppFrame, nested SplitPane regions, DockArea slots, PanelFrame chrome, and optional TabContainer stacks — replacing the ad-hoc pattern of one movable UIHost per panel.

@ownership Returned WidgetDesc trees are values owned by the caller. @thread Call on the UI / main thread that owns the workspace snapshot. @reentrancy Does not invoke content builders while holding locks; builders must not mutate the workspace they are reading.
