详细描述

Native runtime state for Pcg BiomeController placement and automatic terrain loading bounds.

State updates validate a complete candidate before publishing it. The class owns no scene objects and invokes no callbacks; callers use tierAt() to feed their terrain residency scheduler. @thread Game thread only.
