详细描述

Procedural hair/fur card meshes + material/LOD helpers (no strand simulation).

Built-in Kajiya-Kay hair/fur card shader helpers.

Cards are oriented quads suitable for the built-in hair transparent pass. Strand flow is along +V (card height); the hair shader derives tangents from that convention unless strandDir is overridden.

◆ BindingDeformMode

enum class eve::graphics::hair::BindingDeformMode : uint8_t
strong

How bound strands follow a deformed skin triangle.

  • Rigid: translate the whole curve by (skinnedRoot − restRoot).
  • Offset: also rotate the rest offset by the rest→deformed triangle normal.

Neither mode is a full skinned RBF (UE optional path); see design doc Phase 4.

◆ InterpolationMode

enum class eve::graphics::hair::InterpolationMode : uint8_t
strong

How render strands follow deformed guides (UE interpolation analogue).

  • Rigid: weighted guide root translation applied to the whole strand.
  • Offset: per-point delta sampled along each guide at the same u.
  • Smooth: Offset with softer distance weights (more guides influence).
