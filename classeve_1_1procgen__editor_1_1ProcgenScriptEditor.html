详细描述

Workspace controller for one encapsulated procedural script module.

Owns the Params document and local undo. Script presenters run generate and publish copied PointSets; a stale or failed rebuild keeps the last successful preview on screen.

@ownership Editor owns the document and preview copies. PointSet arguments are borrowed only for the publish call. @threadaffinity Owner thread only. @reentrancy Does not invoke script generate callbacks.
