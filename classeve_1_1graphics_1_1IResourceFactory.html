const std::string &  fragWgsl 
)
pure virtual

Create a 2D custom shader from WGSL source (WebGPU backend). Empty vert → default textured vertex shader. The fragment WGSL declares the shared 2D bindings (color texture 0, depth texture 1, sampler 2, depth sampler 3, Externals UBO 4) and vs_main/fs_main entry points. Vulkan throws (uses SPIR-V via newShaderFromSpv).
