eve::physics::IWorldBackend3D类 参考abstract

Complete rigid-world execution boundary, bound once to an owning World3D facade. @ownership Owns exactly one native world; child backends own native children of that world. The facade remains sole owner of engine identity, portable topology, query projections and event queues. @thread Simulation thread only between steps. Native callbacks are internal predicates; public events are collected first and published by the facade after returning from the solver. @lifetime Owning query results survive later queries. Legacy query projections live in the facade. 更多...

详细描述

Complete rigid-world execution boundary, bound once to an owning World3D facade. @ownership Owns exactly one native world; child backends own native children of that world. The facade remains sole owner of engine identity, portable topology, query projections and event queues. @thread Simulation thread only between steps. Native callbacks are internal predicates; public events are collected first and published by the facade after returning from the solver. @lifetime Owning query results survive later queries. Legacy query projections live in the facade.

备注
Unsupported operations must return Unsupported before mutation; no hidden alternate solver.
