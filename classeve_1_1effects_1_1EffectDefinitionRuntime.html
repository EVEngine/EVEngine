 Create a typed effect runtime from a registry definition.
 

详细描述

Binds a typed effect runtime to a generation-qualified definition.

DefinitionRegistry and the target EffectInstance are borrowed. They must outlive each synchronous call. Reload uses the common four-policy contract and is atomic with respect to this adapter's typed state; callers explicitly call applyTo to update the container-owned instance.
