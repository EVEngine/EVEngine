详细描述

Behavior for WarshipEntity: layout projection, mobility, orders.

System scope: every live WarshipEntity. View: WarshipEntity components Identity/Definition/Input/Motion/Health/ Hull/Layout/Capabilities/Flags. Reads: Layout cells + function catalogue; Input; Motion targets. Writes: Motion, Capabilities, Flags, event queue. Structural mutations: none while iterating (destroy deferred to callers). Phase: simulation fixed-step (Warship::update).
