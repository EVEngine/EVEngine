详细描述

The canonical owning dynamic value used by data-facing protocols.

A Value owns all recursively contained storage. Object members use std::map, so key traversal and compact JSON serialization are deterministic. Native pointers, ECS handles, renderer objects and other domain-specific values are intentionally not part of this protocol.
