5// HD-2D module: renders 2D tilemaps and 2D sprite characters inside the 3D
6// scene. Both techniques layer on top of the existing graphics 3D pipeline
7// (GBuffer + CSM shadows):
8//
9// * TileMap3D -- extrudes a map::TileLayer into a 3D relief mesh. Every
10// non-empty tile becomes a box whose top face shows the
11// tile's atlas region and whose side walls extrude down to
12// the configured depth (or to the per-tile elevation read
13// from tile metadata). Handed to a graphics::Renderable3D so
14// it picks up depth, shadows and GBuffer automatically.
15// * Sprite3D -- a camera-facing billboard quad in the 3D world carrying a
16// 2D texture (a character / animation frame). It is an ECS
17// graphics::Renderable3D oriented toward the camera each
18// frame (screen-aligned billboard), so it composites
19// into the forward pass and casts shadows like any mesh.
20// Supports a sprite-sheet frame grid so existing 2D
21// animations play in 3D.
22//
23// Script binding: eve.Hd2d (slot hd2d). See module_manifest.cmake.
