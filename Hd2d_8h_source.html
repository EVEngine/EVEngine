3// HD-2D module: renders 2D tilemaps and 2D sprite characters inside the 3D
4// scene. Both techniques layer on top of the existing graphics 3D pipeline
5// (GBuffer + CSM shadows):
6//
7// * TileMap3D -- extrudes a map::TileLayer into a 3D relief mesh. Every
8// non-empty tile becomes a box whose top face shows the
9// tile's atlas region and whose side walls extrude down to
10// the configured depth (or to the per-tile elevation read
11// from tile metadata). Handed to a graphics::Renderable3D so
12// it picks up depth, shadows and GBuffer automatically.
13// * Sprite3D -- a camera-facing billboard quad in the 3D world carrying a
14// 2D texture (a character / animation frame). It is an ECS
15// graphics::Renderable3D oriented toward the camera each
16// frame (cylindrical billboard, upright), so it composites
17// into the forward pass and casts shadows like any mesh.
18// Supports a sprite-sheet frame grid so existing 2D
19// animations play in 3D.
20//
21// Script binding: eve.Hd2d (slot hd2d). See module_manifest.cmake.
